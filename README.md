# 1С:Груминг салон — сдать спринт 2 с нуля

Спринт 1 уже сдан. Файлы базы и выгрузки **утрачены**. Их не ищите и не восстанавливайте из курса: соберите конфигурацию заново в Конфигураторе и сдайте **только спринт 2**.

Спринт 2 проверяет формы, один цикл проведения, заказы клиентов, роли и подсистемы. Всё это стоит на объектах спринта 1. Поэтому сначала заново создаёте справочники, документы и регистры (файл 01), затем сразу доделываете спринт 2 (файл 02). Выгрузку спринта 1 **не** делайте и **не** сдавайте повторно.

Работайте только в учебной платформе **1С:Предприятие 8.3 (8.3.27.2130), версия для разработчиков**. Не собирайте сдачу кодом в других средах.

## Шаг за шагом до сдачи спринта 2

Идите строго по номерам. Не перескакивайте с файла 01 на формы, пока нет конструктора движений. Не выгружайте `.dt`, пока не сделаны файл 02, данные и чек-лист.

### Шаг A. Пустая база

Откройте [docs/00-podgotovka.md](docs/00-podgotovka.md).

1. Если папки `C:\Users\user\Documents\1C\GroomingSalon` нет или она пустая — создайте новую информационную базу (раздел 0.1).
2. Если старая база ещё открывается, но объектов нет или вы в ней не уверены — тоже создайте новую (можно другую папку, например `C:\Users\user\Documents\1C\GroomingSalon2`). Не смешивайте обломки старой базы с новой.
3. Откройте **Конфигуратор**, заполните свойства корня. **Версия сразу `2.0.0.1`**.
4. Сохраните конфигурацию и обновите базу данных.

### Шаг B. Заново все объекты спринта 1

Откройте [docs/01-sprint-1.md](docs/01-sprint-1.md) и идите по пунктам **1.1 → 1.20**.

Кратко, что должно появиться в дереве:

1. Пять перечислений: типы организаций, типы контрагентов, виды питомцев, полы, типы номенклатуры.
2. Справочники: должности, сотрудники, организации, склады, породы, источники, контрагенты, договоры, номенклатура, пользователи.
3. Документы: запись клиента, реализация, поступление.
4. Регистры: товары на складах (остатки), продажи (обороты).
5. Пункт **1.17** — движения **конструктором** (поступление = приход; реализация = расход склада + продажи по товарам + продажи по услугам).
6. Печатная форма реализации, константа и функциональная опция складов.

Формы, роли и «один цикл» в файле 01 **не** делайте.

### Шаг C. Сразу спринт 2, та же база

Откройте [docs/02-sprint-2.md](docs/02-sprint-2.md). Версия корня уже `2.0.0.1`.

1. Управляемые формы по макетам (переключатели, страницы, видимость).
2. Регистр **Заказы клиентов**.
3. Проведение записи клиента; в реализации **заменить** два конструкторских цикла по товарам на **один**.
4. Параметр сеанса, общий модуль, пользователи информационной базы Мазаева и Оператор.
5. Две роли, подсистемы, начальная страница — журнал записей.

### Шаг D. Данные

Откройте [docs/03-dannye.md](docs/03-dannye.md). Введите карточки и проведите документы. Проверьте роли и опцию складов.

### Шаг E. Выгрузка только спринта 2

Откройте [docs/04-sdacha.md](docs/04-sdacha.md). Чек-лист, затем **Администрирование** → **Выгрузить информационную базу** → `КибальникСА_Спринт2_ГрумингСалон.dt` → ZIP на сдачу.

Внутри файлов каждый пункт — куда нажать в Конфигураторе 8.3.27. Сокращений «ПКМ», «ТЧ», «ТЗ», «15.2» нет. Имена объектов копируйте как есть.
