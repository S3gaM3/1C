# 1С:Груминг салон

Это пошаговая инструкция для полного новичка: как собрать учебную конфигурацию **в Конфигураторе 1С:Предприятие**, а не кодом в других средах.

Курс проверяет не только набор объектов, но и то, что вы сами применяете приёмы из уроков. Файл выгрузки информационной базы с расширением `.dt` нужно получить **своими руками** в Конфигураторе. Эта папка — конспект «куда нажать» и «что вписать в поля».

## Как пользоваться

Идите по файлам **строго по порядку**. Внутри файла каждый пункт — куда нажать в Конфигураторе и что вписать. Не перескакивайте на спринт 2, пока не проведены документы спринта 1.

| Файл | Зачем этот файл |
| --- | --- |
| [docs/00-podgotovka.md](docs/00-podgotovka.md) | Создать пустую информационную базу, заполнить свойства конфигурации, выбрать русский язык, научиться сохранять и обновлять базу |
| [docs/01-sprint-1.md](docs/01-sprint-1.md) | Справочники, перечисления, документы, регистры накопления, функциональная опция складов, движения конструктором, печатная форма |
| [docs/02-sprint-2.md](docs/02-sprint-2.md) | Формы по макетам, проведение в одном цикле, печать, роли, подсистемы, параметр сеанса |
| [docs/03-dannye.md](docs/03-dannye.md) | Готовые значения для вставки в карточки и документы в режиме 1С:Предприятие |
| [docs/04-sdacha.md](docs/04-sdacha.md) | Чек-лист проверки и выгрузка файла `.dt` в архив ZIP |

В инструкциях **нет сокращений** вроде «табличная часть пишется как ТЧ», «ПКМ», «ТЗ», «15.2». Если встречается слово из интерфейса Конфигуратора (Синоним, Реквизит, Параметры выбора), оно написано так, как на экране. Имена объектов платформы (`ЗаписьКлиента`, `Отбор.Владелец`) оставляйте **точно как в тексте**, без пробелов.

## Что сдавать

- Спринт 1: файл `ФамилияИнициалы_Спринт1_ГрумингСалон.dt` внутри архива ZIP, версия конфигурации `1.0.0.1`
- Спринт 2: файл `ФамилияИнициалы_Спринт2_ГрумингСалон.dt` внутри архива ZIP, версия конфигурации `2.0.0.1`

Имя конфигурации — `ГрумингСалон`. Синоним конфигурации — `1С:Груминг салон`. Поставщик — ваши фамилия и имя.

Не собирайте файл `.dt` генераторами и не сдавайте веб-клон интерфейса 1С. Ревьюер открывает вашу информационную базу в Конфигураторе и смотрит дерево объектов, модули и формы.
