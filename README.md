## 4. Починить то, что сейчас сломано

Делайте по пунктам. После блока — сохранить и обновить.

### 4.1. Отбор клиента у записи клиента

Сейчас у реквизита `Клиент` документа `ЗаписьКлиента` **Параметры выбора пустые**, а отбор `Отбор.ТипКонтрагента` = Клиент по ошибке стоит у `Ответственный`.

1. Документ `ЗаписьКлиента` → вкладка **Данные** → реквизит `Ответственный` → **Параметры выбора** → **Открыть** → удалите строку с `Отбор.ТипКонтрагента` → **ОК**.
2. Реквизит `Клиент` → **Параметры выбора** → **Открыть** → **Добавить**. Имя: `Отбор.ТипКонтрагента`. Значение: перечисление `ТипыКонтрагентов` → `Клиент` → **ОК**.

### 4.2. Отбор услуги у реализации

Документ `РеализацияТоваровИУслуг` → табличная часть `Услуги` → колонка `Услуга` → **Параметры выбора** → имя `Отбор.ТипНоменклатуры`, значение `Услуга`. Сейчас параметры пустые — в услугу можно выбрать шампунь.

У колонки `Товар` параметры выбора по-прежнему не заполняйте.

### 4.3. Длина наименования договора

Справочник `ДоговорыКонтрагентов` → вкладка **Данные** → длина наименования сейчас **25**. Строка `№ 144 от 17.04.2023 г.` туда не влезет. Поставьте **150**.

### 4.4. Имена областей печати

Макет `ПФ_MXL_РеализацияТоваровИУслуг` уже есть, код менеджера уже вызывает области. В макете сейчас именована **только** область `Заголовок`. Без остальных печать упадёт.

1. Раскройте документ → **Макеты** → дважды `ПФ_MXL_РеализацияТоваровИУслуг`.
2. Выделяйте группы строк слева за номера → правая кнопка мыши → **Свойства** → **Имя**.

Нужны области:

| Имя | Что внутри |
| --- | --- |
| Заголовок | уже есть |
| ШапкаУслуг | №, Услуга, Сумма |
| СтрокаУслуг | параметры НомерСтроки, Услуга, Сумма |
| ШапкаТоваров | №, Товар, Количество, Цена, Сумма |
| СтрокаТоваров | параметры НомерСтроки, Товар, Количество, Цена, Сумма |
| Подвал | Сумма документа, Ответственный |

Ячейки значений: свойства → **Заполнение** = **Параметр**. Модуль менеджера и команду Печать не пересоздавайте.

### 4.5. Сумма поступления при записи

Правая кнопка мыши по `ПоступлениеТоваров` → **Открыть модуль объекта**. Процедуру `ОбработкаПроведения` конструктора **не трогайте** (там уже `ТекСтрокаТовары.Товар`). Добавьте рядом:

```
Процедура ПередЗаписью(Отказ, РежимЗаписи, РежимПроведения)
	СуммаДокумента = Товары.Итог("Сумма");
КонецПроцедуры
```

## 7. Проведение реализации одним циклом — то, что проверяют в спринте 2

Конструктор оставил бы **два** цикла по табличной части Товары. Ревьюер спринта 2 ищет **один** обход товаров: в теле цикла сразу две записи — расход склада и оборот продаж. Затем отдельный цикл по услугам только в регистр Продажи. Заказы клиентов — если заполнен Основание.

В модуле объекта `РеализацияТоваровИУслуг` **замените** старую `ОбработкаПроведения` целиком. Процедуру `ОбработкаЗаполнения` не удаляйте. Комментарии конструктора после замены пропадут — так и нужно.

```
Процедура ПередЗаписью(Отказ, РежимЗаписи, РежимПроведения)
	СуммаДокумента = Услуги.Итог("Сумма") + Товары.Итог("Сумма");
КонецПроцедуры

Процедура ОбработкаПроведения(Отказ, РежимПроведения)

	Движения.ТоварыНаСкладах.Записывать = Истина;
	Движения.Продажи.Записывать = Истина;
	Движения.ЗаказыКлиентов.Записывать = Истина;

	Для Каждого СтрокаТовары Из Товары Цикл
		Если Константы.ИспользоватьСклады.Получить() Тогда
			ДвижениеСклад = Движения.ТоварыНаСкладах.Добавить();
			ДвижениеСклад.ВидДвижения = ВидДвиженияНакопления.Расход;
			ДвижениеСклад.Период = Дата;
			ДвижениеСклад.Номенклатура = СтрокаТовары.Товар;
			ДвижениеСклад.Склад = Склад;
			ДвижениеСклад.Количество = СтрокаТовары.Количество;
		КонецЕсли;
		ДвижениеПродажи = Движения.Продажи.Добавить();
		ДвижениеПродажи.Период = Дата;
		ДвижениеПродажи.Номенклатура = СтрокаТовары.Товар;
		ДвижениеПродажи.Сотрудник = Сотрудник;
		ДвижениеПродажи.Клиент = Клиент;
		ДвижениеПродажи.Сумма = СтрокаТовары.Сумма;
	КонецЦикла;

	Для Каждого СтрокаУслуги Из Услуги Цикл
		ДвижениеПродажи = Движения.Продажи.Добавить();
		ДвижениеПродажи.Период = Дата;
		ДвижениеПродажи.Номенклатура = СтрокаУслуги.Услуга;
		ДвижениеПродажи.Сотрудник = Сотрудник;
		ДвижениеПродажи.Клиент = Клиент;
		ДвижениеПродажи.Сумма = СтрокаУслуги.Сумма;
	КонецЦикла;

	Если ЗначениеЗаполнено(Основание) Тогда
		ДвижениеЗаказ = Движения.ЗаказыКлиентов.Добавить();
		ДвижениеЗаказ.Период = Дата;
		ДвижениеЗаказ.Клиент = Клиент;
		ДвижениеЗаказ.ЗаписьКлиента = Основание;
		ДвижениеЗаказ.СуммаПлан = 0;
		ДвижениеЗаказ.СуммаФакт = Услуги.Итог("Сумма");
	КонецЕсли;

КонецПроцедуры
```

Сумму документа считают **при записи**, не при каждом изменении строки. Сохранить и обновить.

## 8. Как создать форму

Формы в 8.3.27 — **управляемые**. Повторяйте этот рецепт для каждого объекта.

### Форма элемента справочника

1. Раскройте справочник плюсиком → ветка **Формы**.
2. Insert → тип мастера **Форма элемента справочника**. Имя оставьте `ФормаЭлемента`.
3. Если мастер предлагает галочки реквизитов — отметьте нужные → **Готово**. Если пустая форма — перетащите реквизиты из окна **Реквизиты** (дерево `Объект`) на холст.
4. Порядок полей: в дереве **Элементы** перетащите строки выше или ниже.
5. Переключатель (две кнопки в одной рамке на макете: Юрлицо / ИП, Клиент / Поставщик, Кошка / Собака): щёлкните поле на форме → палитра **элемента** (в заголовке имя элемента, не имя справочника) → **Вид** = **Поле переключателя**. Для перечисления значения подтянутся сами. Это не выпадающий список.
6. Назначить основной: закройте форму, согласитесь сохранить. Окно справочника → вкладка **Формы** → **Основная форма элемента** → лупа → ваша форма.

### Событие поля

1. Выделите поле одним щелчком.
2. Палитра элемента → группа **События** → **ПриИзменении** → лупа.
3. Платформа создаст процедуру в модуле формы. Пишите внутрь неё, не создавайте вторую с тем же именем.

### Модуль формы

В редакторе формы кнопка **Модуль** (внизу или на панели). Заголовок окна должен содержать `ФормаЭлемента`, не «модуль объекта».

Клиентские процедуры — директива `&НаКлиенте`, серверные — `&НаСервере`. Не используйте `&НаСервереБезКонтекста` там, где нужен `Объект`.

Ошибка «Переменная не определена (Объект)» значит одно из трёх:

- код попал в модуль **объекта** справочника (правая кнопка мыши по справочнику → Открыть модуль объекта) — вырежьте, вставьте в модуль **формы**;
- у процедуры `&НаСервереБезКонтекста` — замените на `&НаКлиенте` или `&НаСервере` как в образце;
- форма создана не как форма элемента, в реквизитах нет `Объект`. Удалите форму и создайте заново типом **Форма элемента справочника**.

### Форма списка

Insert → тип **Форма списка**, имя `ФормаСписка`. Лишнюю колонку: правая кнопка мыши по колонке в дереве элементов → **Удалить**. Основная форма списка — вкладка **Формы** объекта. Для дерева: таблица списка → палитра → **Отображение** = `Дерево`.

### Форма документа

Так же, тип **Форма документа**, имя `ФормаДокумента`. Стандартные кнопки «Провести и закрыть», «Записать», «Провести» появятся сами.

После каждой формы — сохранить и обновить.

## 9. Форма Организации (пересобрать)

Сейчас у справочника `Организации` форма с именем `ФормаЭлемента` на самом деле **форма списка**: внутри таблица `Список`, поля смотрят в `Items.Список.CurrentData`. Её назначили основной формой **списка**. Модуль при этом написан для карточки (`Объект.ТипОрганизации`) — поэтому снова будет «Переменная не определена (Объект)».

1. Дважды откройте справочник `Организации` → вкладка **Формы**.
2. Поле **Основная форма списка** очистите (крестик).
3. Раскройте ветку **Формы** у справочника. Правая кнопка мыши по `ФормаЭлемента` → **Удалить**. Согласитесь.
4. Insert по ветке **Формы**. Тип мастера обязательно **Форма элемента справочника** (не форма списка). Имя `ФормаЭлемента`.
5. Поля сверху вниз: ТипОрганизации (переключатель: палитра элемента → **Вид** = **Поле переключателя**), Код, Наименование, ИНН, Руководитель, ДолжностьРуководителя, ГлавныйБухгалтер.
6. Имя элемента бухгалтера в палитре должно быть `ГлавныйБухгалтер`. Если другое — переименуйте элемент.
7. Поле ТипОрганизации → события → ПриИзменении → лупа.
8. Кнопка **Модуль**. Замените модуль формы целиком:

```
&НаКлиенте
Процедура ПриОткрытии(Отказ)
	УстановитьВидимостьГлавногоБухгалтера();
КонецПроцедуры

&НаКлиенте
Процедура ТипОрганизацииПриИзменении(Элемент)
	УстановитьВидимостьГлавногоБухгалтера();
КонецПроцедуры

&НаКлиенте
Процедура УстановитьВидимостьГлавногоБухгалтера()
	ЭтоЮрЛицо = Объект.ТипОрганизации
		= ПредопределенноеЗначение("Перечисление.ТипыОрганизаций.ЮридическоеЛицо");
	Элементы.ГлавныйБухгалтер.Видимость = ЭтоЮрЛицо;
КонецПроцедуры
```

Если платформа создала пустую `ПриСозданииНаСервере` — оставьте пустой или удалите вызов из неё. Не создавайте вторую `ТипОрганизацииПриИзменении`.

Форма списка: Insert → тип **Форма списка**, имя `ФормаСписка`. Колонки: Тип организации, Наименование, ИНН, Код. Вкладка **Формы** справочника: **Основная форма элемента** = `ФормаЭлемента`, **Основная форма списка** = `ФормаСписка`.

Проверка в предприятии: переключите тип на ИП — главный бухгалтер исчезает. Верните юридическое лицо. Реквизит не удаляйте, меняется только видимость.

## 10. Форма пород (доделать)

Форма элемента и форма списка уже есть. Код подстановки родителя уже в модуле. Список уже деревом.

Откройте форму элемента. Поле `ВидПитомца` сейчас обычное поле ввода: щёлкните его → палитра элемента → **Вид** = **Поле переключателя**.

Порядок полей: Код; ВидПитомца; Порода (стандартное Наименование); Родитель.

Событие ВидПитомца → ПриИзменении уже должно быть таким (если лупа создала пустую процедуру — вставьте этот текст):

```
&НаКлиенте
Процедура ВидПитомцаПриИзменении(Элемент)
	Если Объект.ВидПитомца = ПредопределенноеЗначение("Перечисление.ВидыПитомцев.Кошка") Тогда
		Объект.Родитель = ПредопределенноеЗначение("Справочник.ПородыПитомцев.Кошки");
	ИначеЕсли Объект.ВидПитомца = ПредопределенноеЗначение("Перечисление.ВидыПитомцев.Собака") Тогда
		Объект.Родитель = ПредопределенноеЗначение("Справочник.ПородыПитомцев.Собаки");
	КонецЕсли;
КонецПроцедуры
```

Форма списка: колонки Порода, Код, Вид питомца. Таблица списка → **Отображение** = `Дерево`. Назначьте основной формой списка. Список сразу деревом, без «Ещё → Режим просмотра».

## 11. Форма контрагентов

Нужны **страницы**. Страницы — группа элементов, у которой **Вид** = `Страницы`.

1. В дереве элементов формы: **Добавить** → **Группа** → вид **Страницы**.
2. Внутри две группы вида **Страница**: `СтраницаОсновное` (заголовок «Основное») и `СтраницаДоговоры` (заголовок «Договоры»).
3. Перетащите поля на нужную страницу.

Сверху на Основном: **ТипКонтрагента** — переключатель Клиент / Поставщик.

Если тип = Клиент, видны: Код; Наименование с заголовком **Ф.И.О. клиента**; Контактный телефон; Дата рождения; Пол; Источник; таблица Питомцы (Вид, Порода, Кличка, Дата рождения); Комментарий.

Если тип = Поставщик, видны: Код; Наименование; Контактный телефон; Основной договор; Комментарий. Поля клиента скрывает код, реквизиты из справочника не удаляйте.

Страница Договоры: реквизит формы (не справочника) имя `ДоговорыКонтрагента`, тип **ДинамическийСписок**, основная таблица `Справочник.ДоговорыКонтрагентов`, отбор владелец = `Объект.Ссылка`. Список доступен после записи элемента.

Имена элементов `ДатаРождения`, `Пол`, `Источник`, `Питомцы`, `ОсновнойДоговор`, `Наименование` должны совпасть с кодом.

```
&НаСервере
Процедура ПриСозданииНаСервере(Отказ, СтандартнаяОбработка)
	НастроитьФормуПоТипу();
КонецПроцедуры

&НаКлиенте
Процедура ТипКонтрагентаПриИзменении(Элемент)
	НастроитьФормуПоТипу();
	Если Объект.ТипКонтрагента = ПредопределенноеЗначение("Перечисление.ТипыКонтрагентов.Клиент") Тогда
		Объект.Родитель = ПредопределенноеЗначение("Справочник.Контрагенты.Клиенты");
	Иначе
		Объект.Родитель = ПредопределенноеЗначение("Справочник.Контрагенты.Поставщики");
	КонецЕсли;
КонецПроцедуры

&НаСервере
Процедура НастроитьФормуПоТипу()
	ЭтоКлиент = Объект.ТипКонтрагента = Перечисления.ТипыКонтрагентов.Клиент;
	Элементы.ДатаРождения.Видимость = ЭтоКлиент;
	Элементы.Пол.Видимость = ЭтоКлиент;
	Элементы.Источник.Видимость = ЭтоКлиент;
	Элементы.Питомцы.Видимость = ЭтоКлиент;
	Элементы.ОсновнойДоговор.Видимость = Не ЭтоКлиент;
	Если ЭтоКлиент Тогда
		Элементы.Наименование.Заголовок = "Ф.И.О. клиента";
	Иначе
		Элементы.Наименование.Заголовок = "Наименование";
	КонецЕсли;
КонецПроцедуры
```

Форма списка: **Отображение** = `Дерево`. Колонки: Наименование, Код, Тип контрагента, Контактный телефон, Дата рождения клиента, Пол, Договор, Источник, Комментарий.

## 12. Форма договоров

Поле **Наименование** только для просмотра: элемент → палитра → **ТолькоПросмотр** = Да.

Поля сверху вниз: Код, Наименование, Владелец, Номер договора, Дата заключения и Действует до в одной горизонтальной группе, Бессрочный, Комментарий.

Горизонтальная группа: **Добавить** → группа вида **Обычная группа**, группировка **Горизонтальная**, перетащите в неё оба поля дат.

Имя элемента «Действует до» должно быть `СрокДействия`. Если мастер назвал иначе — переименуйте.

События ПриИзменении: НомерДоговора и ДатаЗаключения вызывают `СформироватьНаименование`; Бессрочный вызывает `НастроитьСрок`.

```
&НаКлиенте
Процедура ПриОткрытии(Отказ)
	СформироватьНаименование();
	НастроитьСрок();
КонецПроцедуры

&НаКлиенте
Процедура НомерДоговораПриИзменении(Элемент)
	СформироватьНаименование();
КонецПроцедуры

&НаКлиенте
Процедура ДатаЗаключенияПриИзменении(Элемент)
	СформироватьНаименование();
КонецПроцедуры

&НаКлиенте
Процедура БессрочныйПриИзменении(Элемент)
	НастроитьСрок();
КонецПроцедуры

&НаКлиенте
Процедура СформироватьНаименование()
	Если ПустаяСтрока(Объект.НомерДоговора) Или Не ЗначениеЗаполнено(Объект.ДатаЗаключения) Тогда
		Возврат;
	КонецЕсли;
	Объект.Наименование = "№ " + Объект.НомерДоговора
		+ " от " + Формат(Объект.ДатаЗаключения, "ДФ=dd.MM.yyyy") + " г.";
КонецПроцедуры

&НаКлиенте
Процедура НастроитьСрок()
	Элементы.СрокДействия.Видимость = Не Объект.Бессрочный;
	Если Объект.Бессрочный Тогда
		Объект.СрокДействия = Дата(1, 1, 1);
	КонецЕсли;
КонецПроцедуры
```

Форма списка: Наименование, Владелец, Номер, даты. Назначьте основной формой списка.

## 13. Формы номенклатуры и сотрудников

### Номенклатура

Форма элемента: Код, Тип номенклатуры (переключатель), Наименование, Родитель.

```
&НаКлиенте
Процедура ТипНоменклатурыПриИзменении(Элемент)
	Если Объект.ТипНоменклатуры = ПредопределенноеЗначение("Перечисление.ТипыНоменклатуры.Услуга") Тогда

		Объект.Родитель = ПредопределенноеЗначение("Справочник.Номенклатура.Товары");

	КонецЕсли;
КонецПроцедуры
```

Форма списка: наименование, код, тип.

### Сотрудники

Форма элемента: Таб.№, Ф.И.О. (только просмотр), Фамилия, Имя, Отчество, Пол, Дата рождения, Должность, Контактный телефон.

События ПриИзменении у Фамилия, Имя, Отчество:

```
&НаКлиенте
Процедура ФамилияПриИзменении(Элемент)

КонецПроцедуры

&НаКлиенте
Процедура ИмяПриИзменении(Элемент)
	СобратьФИО();
КонецПроцедуры

&НаКлиенте
Процедура ОтчествоПриИзменении(Элемент)
	СобратьФИО();
КонецПроцедуры

&НаКлиенте
Процедура СобратьФИО()
	Объект.Наименование = СокрЛП(Объект.Фамилия + " " + Объект.Имя + " " + Объект.Отчество);

```

Форма выбора (отдельная, имя `ФормаВыбора`): колонки Таб.№, Ф.И.О., Должность. На вкладке **Формы** справочника **Основная форма выбора** = эта форма.

Форма списка: Таб.№, Ф.И.О., Должность, Дата рождения, Контактный телефон.

### Пользователи

Основную форму элемента можно оставить сгенерированной: Идентификатор, Имя пользователя. Кнопки создания у оператора убирает **роль** (шаг 21), а не удаление кнопки с формы администратора.

## 14. Формы документов

### 19.1. Запись клиента

1. Документ `ЗаписьКлиента` → Формы → Insert → **Форма документа**.
2. Страницы: группа вида Страницы, две страницы **Основное** и **Заказы клиентов**.
3. Шапка в две колонки: обычная группа с горизонтальной группировкой.

Расположение:

- Номер | поле «От» = Дата
- Сотрудник | рядом нередактируемое поле Должность
- Клиент | рядом № телефона
- Дата записи
- табличная часть Услуги: Услуга, Стоимость
- внизу Комментарий | Ответственный

Поля **Должность** и **№ телефона** — это **не** реквизиты документа. Окно **Реквизиты** редактора формы (не дерево конфигурации) → правая кнопка мыши по корню реквизитов формы → **Добавить**:

- имя `ДолжностьСотрудника`, тип ссылка на `Должности`;
- имя `ТелефонКлиента`, тип Строка, длина 20.

Перетащите их на форму рядом с Сотрудник и Клиент. **ТолькоПросмотр** = Да.

Модуль формы. Строки с `ПараметрыСеанса` заработают после шага 15; до этого их можно временно закомментировать, затем вернуть.

```
&НаСервере
Процедура ПриСозданииНаСервере(Отказ, СтандартнаяОбработка)
	Если Не ЗначениеЗаполнено(Объект.Ссылка) Тогда
		Объект.Ответственный = ПараметрыСеанса.ТекущийПользователь;
	КонецЕсли;
	ЗаполнитьПоляПросмотра();
КонецПроцедуры

&НаСервере
Процедура ЗаполнитьПоляПросмотра()
	Если ЗначениеЗаполнено(Объект.Сотрудник) Тогда
		ДолжностьСотрудника = Объект.Сотрудник.Должность;
	Иначе
		ДолжностьСотрудника = Справочники.Должности.ПустаяСсылка();
	КонецЕсли;
	Если ЗначениеЗаполнено(Объект.Клиент) Тогда
		ТелефонКлиента = Объект.Клиент.КонтактныйТелефон;
	Иначе
		ТелефонКлиента = "";
	КонецЕсли;
КонецПроцедуры

&НаКлиенте
Процедура СотрудникПриИзменении(Элемент)
	ЗаполнитьПоляПросмотра();
КонецПроцедуры

&НаКлиенте
Процедура КлиентПриИзменении(Элемент)
	ЗаполнитьПоляПросмотра();
КонецПроцедуры
```

События ПриИзменении у полей Сотрудник и Клиент создайте лупой, не дублируйте процедуры.

Панель навигации: в редакторе формы кнопка **Командный интерфейс** → слева **Панель навигации** → перетащите регистр **Заказы клиентов**.

Форма списка: колонки Дата, Номер, Дата записи, Сотрудник, Клиент, Ответственный. Синоним формы `Журнал записи клиентов`. В командном интерфейсе списка включите стандартную команду **Создать на основании** реализации.

### 19.2. Реализация товаров и услуг

Страница **Основное**. Внутри неё ещё страницы **Услуги** / **Товары**. Шапка: Номер, Дата, Клиент, Сотрудник, Склад, Основание. Поле СуммаДокумента — только просмотр. Под таблицей можно включить **Подвал** = Да.

Панель навигации формы: регистры Заказы клиентов, Продажи, Товары на складах. Команду **Печать** перетащите на командную панель формы.

Сумма **строки** товаров (не сумма документа) при изменении количества или цены:

```
&НаКлиенте
Процедура ТоварыКоличествоПриИзменении(Элемент)
	ПересчитатьСуммуСтроки();
КонецПроцедуры

&НаКлиенте
Процедура ТоварыЦенаПриИзменении(Элемент)
	ПересчитатьСуммуСтроки();
КонецПроцедуры

&НаКлиенте
Процедура ПересчитатьСуммуСтроки()
	СтрокаТЧ = Элементы.Товары.ТекущиеДанные;
	Если СтрокаТЧ = Неопределено Тогда
		Возврат;
	КонецЕсли;
	СтрокаТЧ.Сумма = СтрокаТЧ.Количество * СтрокаТЧ.Цена;
КонецПроцедуры

&НаСервере
Процедура ПриСозданииНаСервере(Отказ, СтандартнаяОбработка)
	Если Не ЗначениеЗаполнено(Объект.Ссылка) Тогда
		Объект.Ответственный = ПараметрыСеанса.ТекущийПользователь;
	КонецЕсли;
КонецПроцедуры
```

Имя `СтрокаТЧ` — служебное имя переменной, не переименовывайте, если копируете как есть.

Форма списка: Дата, Номер, Клиент, Сотрудник, Сумма документа, Основание, Ответственный, Комментарий.

### 19.3. Поступление товаров

Расположение: Номер | Дата; Номер входящего | Дата входящего; Поставщик | Договор; Склад; таблица; сумма документа только просмотр; Комментарий | Ответственный.

Колонка **Тип номенклатуры** — не новый реквизит табличной части. Выделите таблицу Товары → добавьте поле → **Путь к данным** = `Объект.Товары.Товар.ТипНоменклатуры` (лупа выбора) → **ТолькоПросмотр** = Да.

Пересчёт Количество × Цена = Сумма строки — те же клиентские процедуры, что у реализации, только таблица поступления (`Элементы.Товары.ТекущиеДанные`). Сумма документа — уже есть `ПередЗаписью` на шаге 4.

Панель навигации: регистр Товары на складах. Автор из параметра сеанса, как у записи клиента.

Форма списка: Дата, Номер, Дата входящая, Номер входящий, Поставщик, Договор, Сумма документа, Склад.

## 15. Параметр сеанса и пользователи

### 20.1. Параметр сеанса
