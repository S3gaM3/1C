## 0. Как открыть именно эту базу

1. Если архив лежит отдельно от рабочей папки: распакуйте `GroomingSalon.zip` в каталог базы. Внутри должны быть `1Cv8.1CD` и папка `1Cv8Log`. Не создавайте поверх этого «информационную базу без конфигурации».
2. Ярлык **1С:Предприятие** → окно списка информационных баз.
3. Если строки **Груминг салон** нет: справа **Добавить** → точка **Добавление в список существующей информационной базы** → **Далее** → наименование `Груминг салон` → каталог укажите папку с `1Cv8.1CD` → **Готово**.
4. Выделите строку **Груминг салон** → справа кнопка **Конфигуратор** (не **1С:Предприятие**).
5. Меню **Конфигурация** → **Открыть конфигурацию**. Слева появится дерево с корнем `ГрумингСалон`.
6. Проверка платформы: меню **Справка** → **О программе**. Должно быть **8.3.27.2130**, приложение **Конфигуратор**.

Если дерево пустое или корень называется иначе — вы открыли не ту папку. Закройте Конфигуратор и укажите каталог из архива.

## 1. Общие приёмы Конфигуратора

### 1.1. Три окна

- **Дерево конфигурации** — слева. Ветки: Общие, Константы, Справочники, Документы, Перечисления, Регистры накопления.
- **Окно объекта** — центр. Двойной щелчок по объекту. Вкладки: **Данные**, **Формы**, **Нумерация**, **Иерархия**, **Владельцы**, **Движения**, **Ввод на основании**, **Прочее**.
- **Палитра свойств** — справа. Смотрите заголовок палитры: «Справочник Сотрудники» — свойства всего справочника; «Реквизит Фамилия» — одно поле. Если палитра не та — щёлкните нужную строку на вкладке **Данные** ещё раз.

У длинных свойств справа часто кнопка **Открыть** (стандартные реквизиты, параметры выбора, связи параметров выбора).

### 1.2. Как добавить объект, если нет пункта «Добавить»

Правая кнопка мыши показывает **Добавить** только если выделена **сама ветка**: строка **Константы**, **Функциональные опции**, **Формы**, **Регистры накопления**.

Не сработает, если щёлкнули пустое место, корень `ГрумингСалон`, уже созданный объект, вкладку **Состав** или строку **Параметры функциональных опций**.

Сначала **левой** кнопкой один раз щёлкните заголовок ветки, чтобы строка стала синей. Потом любой из способов:

1. Клавиша **Insert**.
2. Зелёный плюс над деревом конфигурации.
3. Меню **Действия** над деревом → **Добавить**.
4. Правая кнопка мыши по уже выделенной строке ветки → **Добавить**.

### 1.3. Сохранить и обновить

После каждого крупного блока:

1. Меню **Конфигурация** → **Сохранить конфигурацию** (клавиши Ctrl и S).
2. Меню **Конфигурация** → **Обновить конфигурацию базы данных** (клавиша F7).
3. В окне реорганизации нажмите **Принять**.

Дальше в этой инструкции это называется «сохранить и обновить». Если F7 пишет про регистратор — сначала шаг 5, потом снова обновить.

Режим предприятия для проверки: меню **Отладка** → **Начать отладку**. Либо закройте Конфигуратор и из списка баз нажмите **1С:Предприятие**.

### 1.4. Числа, строки, обязательность

В учебном задании «15.2» означает: тип **Число**, **Длина** `15`, **Точность** `2` (два знака после запятой). «15.3» — длина 15, точность 3. Это не версия платформы.

Неограниченная строка: тип Строка, длина `0`.

Обязательное поле: палитра реквизита → **Проверка заполнения** = **Выдавать ошибку**.

Тип выбирают кнопкой **T** у свойства **Тип**: слева вид (`Строка`, `Число`, `Булево`, `СправочникСсылка`, `ПеречислениеСсылка`, `ДокументСсылка`), справа конкретный объект или длина.

**Параметры выбора** — постоянный отбор («всегда только Клиент»). **Связи параметров выбора** — отбор от другого поля этой же карточки (`Отбор.Владелец` = Поставщик). Это две разные строки палитры.

Табличная часть — таблица внизу карточки или документа. Её добавляют в **нижнем** блоке вкладки **Данные**, не плюсом в верхнем списке реквизитов шапки.

## 5. Регистраторы регистров

Иначе обновление базы (клавиша F7) пишет: «Ни один из документов не является регистратором». Текст про регистр **Продажи** значит: регистр создан, галочка регистратора не стоит.

1. Нажмите **ОК** в окне ошибки, если оно открыто. База пока не обновится — это нормально.
2. Дерево → **Регистры накопления** → дважды `Продажи` → вкладка **Регистраторы**.
3. Поставьте галочку **только** на `РеализацияТоваровИУслуг`. У поступления галочки здесь быть не должно.
4. Дважды `ТоварыНаСкладах` → **Регистраторы** → галочки на `ПоступлениеТоваров` и `РеализацияТоваровИУслуг`.
5. Если список документов пустой: откройте документ → вкладка **Движения** → поставьте галочки на нужных регистрах. Это тот же смысл с другой стороны. Затем снова проверьте вкладку **Регистраторы** у регистра.
6. Если вкладки «Регистраторы» нет: выделите регистр → палитра → строка **Регистраторы** → **Открыть**.

## 6. Проведение поступления

Ревьюер спринта 1 смотрит, что код сделал **конструктор**. Если конструктор уже оставил цикл с `ТекСтрокаТовары.Товар` — не трогайте. Если модуля нет или проверка пишет «Переменная не определена (Товар)» — сначала попробуйте конструктор, затем запасной текст.

### 6.1. Конструктор

1. Дважды откройте документ `ПоступлениеТоваров`.
2. Вкладка **Движения**.
3. Галочка на регистре **ТоварыНаСкладах**. Регистр **Продажи** у поступления не включайте.
4. Кнопка **Конструктор движений**.
5. Регистр `ТоварыНаСкладах`, вид движения **Приход**, табличная часть **Товары**.
6. В таблице соответствия щёлкните ячейку **Выражение**, затем **дважды** щёлкните поле справа:

| Поле регистра | Выражение | Откуда двойным щелчком |
| --- | --- | --- |
| Номенклатура | `Товар` | колонка табличной части Товары |
| Склад | `Склад` | реквизит шапки документа, не слово «шапка» |
| Количество | `Количество` | колонка табличной части Товары, не Сумма |

7. **Выполнить**. Согласитесь создать процедуру `ОбработкаПроведения`.

### 6.2. Если «Переменная не определена (Товар)»

Конструктор записал поле шапки вместо колонки строки. Должно быть `ТекСтрокаТовары.Товар` и `ТекСтрокаТовары.Количество`. Склад, Дата — из шапки, без приставки.

Правая кнопка мыши по документу `ПоступлениеТоваров` → **Открыть модуль объекта**. Замените проведение на это (имена цикла оставьте как есть):

```
Процедура ОбработкаПроведения(Отказ, Режим)

	Движения.ТоварыНаСкладах.Записывать = Истина;
	Для Каждого ТекСтрокаТовары Из Товары Цикл
		Движение = Движения.ТоварыНаСкладах.Добавить();
		Движение.ВидДвижения = ВидДвиженияНакопления.Приход;
		Движение.Период = Дата;
		Движение.Номенклатура = ТекСтрокаТовары.Товар;
		Движение.Склад = Склад;
		Движение.Количество = ТекСтрокаТовары.Количество;
	КонецЦикла;

КонецПроцедуры
```

Комментарии конструктора `//{{__КОНСТРУКТОР_ДВИЖЕНИЙ_РЕГИСТРОВ` для поступления можно оставить. Не запускайте конструктор повторно после ручной правки — он затрёт исправления.

Добавьте рядом (не внутри цикла):

```
Процедура ПередЗаписью(Отказ, РежимЗаписи, РежимПроведения)
	СуммаДокумента = Товары.Итог("Сумма");
КонецПроцедуры
```

Сохранить и обновить.

Проведение **реализации** конструктором с двумя циклами по товарам сейчас не делайте: на шаге 12 вы всё равно замените его одним циклом. Галочки движений у реализации поставьте: ТоварыНаСкладах и Продажи. Регистр заказов отметите после шага 10.

## 8. Печатная форма реализации

Учебный курс печатает командой, без библиотеки стандартных подсистем. Не копируйте `УправлениеПечатью`.

### 8.1. Макет

1. Раскройте документ `РеализацияТоваровИУслуг` в дереве.
2. Ветка **Макеты** → Insert (или зелёный плюс) → тип **Табличный документ**.
3. Имя: `ПФ_MXL_РеализацияТоваровИУслуг`. Синоним: `Реализация товаров и услуг`.
4. Откроется сетка как в Excel.

Именованные области (иначе код не найдёт куски):

1. Выделите несколько строк мышью за номера строк слева.
2. Правая кнопка мыши по выделенным номерам → **Свойства**.
3. **Имя** области — из таблицы ниже.

| Имя области | Что внутри |
| --- | --- |
| Заголовок | текст «Реализация товаров и услуг»; подписи Номер, Дата, Клиент, Сотрудник, Основание |
| ШапкаУслуг | шапка таблицы: №, Услуга, Сумма |
| СтрокаУслуг | параметры НомерСтроки, Услуга, Сумма |
| ШапкаТоваров | №, Товар, Количество, Цена, Сумма |
| СтрокаТоваров | параметры НомерСтроки, Товар, Количество, Цена, Сумма |

В ячейках значений: свойства ячейки → **Заполнение** = **Параметр**. Имена параметров: `Номер`, `Дата`, `Клиент`, `Сотрудник`, `Основание`, `НомерСтроки`, `Услуга`, `Сумма`, `Товар`, `Количество`, `Цена`, `СуммаДокумента`, `Ответственный`.

### 8.2. Модуль менеджера

Правая кнопка мыши по документу `РеализацияТоваровИУслуг` → **Открыть модуль менеджера**. Вставьте:

```
Функция СформироватьПечатнуюФорму(Документ) Экспорт

	ТабДок = Новый ТабличныйДокумент;
	Макет = Документы.РеализацияТоваровИУслуг.ПолучитьМакет("ПФ_MXL_РеализацияТоваровИУслуг");
	ОбластьЗаголовок = Макет.ПолучитьОбласть("Заголовок");
	ОбластьЗаголовок.Параметры.Заполнить(Документ);
	ТабДок.Вывести(ОбластьЗаголовок);

	Если Документ.Услуги.Количество() > 0 Тогда
		ТабДок.Вывести(Макет.ПолучитьОбласть("ШапкаУслуг"));
		ОбластьСтрока = Макет.ПолучитьОбласть("СтрокаУслуг");
		НомерСтроки = 0;
		Для Каждого СтрокаТЧ Из Документ.Услуги Цикл
			НомерСтроки = НомерСтроки + 1;
			ОбластьСтрока.Параметры.Заполнить(СтрокаТЧ);
			ОбластьСтрока.Параметры.НомерСтроки = НомерСтроки;
			ТабДок.Вывести(ОбластьСтрока);
		КонецЦикла;
	КонецЕсли;

	Если Документ.Товары.Количество() > 0 Тогда
		ТабДок.Вывести(Макет.ПолучитьОбласть("ШапкаТоваров"));
		ОбластьСтрока = Макет.ПолучитьОбласть("СтрокаТоваров");
		НомерСтроки = 0;
		Для Каждого СтрокаТЧ Из Документ.Товары Цикл
			НомерСтроки = НомерСтроки + 1;
			ОбластьСтрока.Параметры.Заполнить(СтрокаТЧ);
			ОбластьСтрока.Параметры.НомерСтроки = НомерСтроки;
			ТабДок.Вывести(ОбластьСтрока);
		КонецЦикла;
	КонецЕсли;

	ОбластьПодвал = Макет.ПолучитьОбласть("Подвал");
	ОбластьПодвал.Параметры.СуммаДокумента = Документ.СуммаДокумента;
	ОбластьПодвал.Параметры.Ответственный = Документ.Ответственный;
	ТабДок.Вывести(ОбластьПодвал);
	Возврат ТабДок;

КонецФункции
```

Условие `Количество() > 0` нужно сразу: пустая таблица товаров на печати не должна выходить.

## 9. Константа и функциональная опция складов

Нужны **два разных объекта** в **разных** ветках. Имена могут совпасть.

| Объект | Где в дереве 8.3.27 |
| --- | --- |
| Константа `ИспользоватьСклады` | верхний уровень, ветка **Константы** (после Общие, перед Справочники) |
| Функциональная опция `ИспользоватьСклады` | **Общие** → **Функциональные опции** |

Не открывайте соседнюю ветку **Параметры функциональных опций**.

### 9.1. Константа

1. Левой кнопкой щёлкните строку **Константы**, чтобы она стала синей.
2. Клавиша Insert (или зелёный плюс, или **Действия** → **Добавить**).
3. Палитра должна быть про константу, не про корень.
4. Имя: `ИспользоватьСклады`. Синоним: `Использовать склады`.
5. Тип: кнопка **T** → слева только **Булево** → **ОК**.
6. Если константа уже есть в дереве — вторую не создавайте.

### 9.2. Опция

1. Раскройте **Общие** (жёлтая папка под корнем).
2. Найдите **Функциональные опции**. Insert.
3. Имя `ИспользоватьСклады`, синоним `Использовать склады`.
4. Строка **Хранение** → лупа / **Открыть** → константа `ИспользоватьСклады`. Если Хранение пустое, опция не работает.

### 9.3. Состав (только галочки, без Insert)

Вкладка **Состав** у опции. Если вкладки нет: палитра → **Состав** → **Открыть**. Раскрывайте плюсики и отмечайте **строки**, новые объекты здесь не создают.

| Где раскрыть | Что отметить |
| --- | --- |
| Справочники | строка `Склады` |
| Документы → `РеализацияТоваровИУслуг` → Реквизиты | реквизит `Склад` |
| Документы → `ПоступлениеТоваров` → Реквизиты | реквизит `Склад` |
| Регистры накопления | строка `ТоварыНаСкладах` |
| Тот же регистр → Измерения | измерение `Склад` |

**Что значит «измерение Склад этого регистра».** Это не новый реквизит и не отдельный справочник. Измерение `Склад` уже есть у регистра `ТоварыНаСкладах` (вместе с `Номенклатура` и ресурсом `Количество`). Сейчас его только **отмечают галочкой** в составе опции, чтобы при выключенных складах поле регистра тоже скрылось.

Как дойти до этой галочки:

1. В окне Состав прокрутите вниз до **Регистры накопления**.
2. Плюсик слева от **Регистры накопления**.
3. Галочка на строке `ТоварыНаСкладах` (весь регистр).
4. Плюсик слева от `ТоварыНаСкладах` → плюсик у **Измерения**.
5. Две строки: `Номенклатура` и `Склад`. Галочка только на **`Склад`**. Строку `Номенклатура` не отмечайте.

Не ставьте галочку на весь документ реализации или поступления — иначе пропадут сами документы, а не поле склада.

### 9.4. Включить флажок в предприятии

Сохранить и обновить. После обновления константа обычно выключена, склады скрыты.

1. **Отладка** → **Начать отладку**.
2. Если нет пункта **Все функции**: **Сервис** → **Параметры** → флажок **Отображать команду «Все функции»** → **ОК**.
3. **Все функции** → **Константы** → Использовать склады = Да. Запишите.
4. Закройте предприятие и откройте снова.

Проверка: поле Склад в поступлении видно, справочник Склады открывается. Перед сдачей флажок держите включённым, иначе складские движения некуда писать. Форму константы в разделе Настройки сделаете на шаге 22.

## 12. Проведение реализации одним циклом — то, что проверяют в спринте 2

Конструктор оставил бы **два** цикла по табличной части Товары. Ревьюер спринта 2 ищет **один** обход товаров: в теле цикла сразу две записи — расход склада и оборот продаж. Затем отдельный цикл по услугам только в регистр Продажи. Заказы клиентов — если заполнен Основание.

В модуле объекта `РеализацияТоваровИУслуг` **замените** старую `ОбработкаПроведения` целиком. Процедуру `ОбработкаЗаполнения` не удаляйте. Комментарии конструктора после замены пропадут — так и нужно.

```
Процедура ПередЗаписью(Отказ, РежимЗаписи, РежимПроведения)
	СуммаДокумента = Услуги.Итог("Сумма") + Товары.Итог("Сумма");
КонецПроцедуры

Процедура ОбработкаПроведения(Отказ, РежимПроведения)

	Движения.ТоварыНаСкладах.Записывать = Истина;
	Движения.Продажи.Записывать = Истина;
	Движения.ЗаказыКлиентов.Записывать = Истина;

	Для Каждого СтрокаТовары Из Товары Цикл
		Если Константы.ИспользоватьСклады.Получить() Тогда
			ДвижениеСклад = Движения.ТоварыНаСкладах.Добавить();
			ДвижениеСклад.ВидДвижения = ВидДвиженияНакопления.Расход;
			ДвижениеСклад.Период = Дата;
			ДвижениеСклад.Номенклатура = СтрокаТовары.Товар;
			ДвижениеСклад.Склад = Склад;
			ДвижениеСклад.Количество = СтрокаТовары.Количество;
		КонецЕсли;
		ДвижениеПродажи = Движения.Продажи.Добавить();
		ДвижениеПродажи.Период = Дата;
		ДвижениеПродажи.Номенклатура = СтрокаТовары.Товар;
		ДвижениеПродажи.Сотрудник = Сотрудник;
		ДвижениеПродажи.Клиент = Клиент;
		ДвижениеПродажи.Сумма = СтрокаТовары.Сумма;
	КонецЦикла;

	Для Каждого СтрокаУслуги Из Услуги Цикл
		ДвижениеПродажи = Движения.Продажи.Добавить();
		ДвижениеПродажи.Период = Дата;
		ДвижениеПродажи.Номенклатура = СтрокаУслуги.Услуга;
		ДвижениеПродажи.Сотрудник = Сотрудник;
		ДвижениеПродажи.Клиент = Клиент;
		ДвижениеПродажи.Сумма = СтрокаУслуги.Сумма;
	КонецЦикла;

	Если ЗначениеЗаполнено(Основание) Тогда
		ДвижениеЗаказ = Движения.ЗаказыКлиентов.Добавить();
		ДвижениеЗаказ.Период = Дата;
		ДвижениеЗаказ.Клиент = Клиент;
		ДвижениеЗаказ.ЗаписьКлиента = Основание;
		ДвижениеЗаказ.СуммаПлан = 0;
		ДвижениеЗаказ.СуммаФакт = Услуги.Итог("Сумма");
	КонецЕсли;

КонецПроцедуры
```

Сумму документа считают **при записи**, не при каждом изменении строки. Сохранить и обновить.

## 13. Как создать форму

Формы в 8.3.27 — **управляемые**. Повторяйте этот рецепт для каждого объекта.

### Форма элемента справочника

1. Раскройте справочник плюсиком → ветка **Формы**.
2. Insert → тип мастера **Форма элемента справочника**. Имя оставьте `ФормаЭлемента`.
3. Если мастер предлагает галочки реквизитов — отметьте нужные → **Готово**. Если пустая форма — перетащите реквизиты из окна **Реквизиты** (дерево `Объект`) на холст.
4. Порядок полей: в дереве **Элементы** перетащите строки выше или ниже.
5. Переключатель (две кнопки в одной рамке на макете: Юрлицо / ИП, Клиент / Поставщик, Кошка / Собака): щёлкните поле на форме → палитра **элемента** (в заголовке имя элемента, не имя справочника) → **Вид** = **Поле переключателя**. Для перечисления значения подтянутся сами. Это не выпадающий список.
6. Назначить основной: закройте форму, согласитесь сохранить. Окно справочника → вкладка **Формы** → **Основная форма элемента** → лупа → ваша форма.

### Событие поля

1. Выделите поле одним щелчком.
2. Палитра элемента → группа **События** → **ПриИзменении** → лупа.
3. Платформа создаст процедуру в модуле формы. Пишите внутрь неё, не создавайте вторую с тем же именем.

### Модуль формы

В редакторе формы кнопка **Модуль** (внизу или на панели). Заголовок окна должен содержать `ФормаЭлемента`, не «модуль объекта».

Клиентские процедуры — директива `&НаКлиенте`, серверные — `&НаСервере`. Не используйте `&НаСервереБезКонтекста` там, где нужен `Объект`.

Ошибка «Переменная не определена (Объект)» значит одно из трёх:

- код попал в модуль **объекта** справочника (правая кнопка мыши по справочнику → Открыть модуль объекта) — вырежьте, вставьте в модуль **формы**;
- у процедуры `&НаСервереБезКонтекста` — замените на `&НаКлиенте` или `&НаСервере` как в образце;
- форма создана не как форма элемента, в реквизитах нет `Объект`. Удалите форму и создайте заново типом **Форма элемента справочника**.

### Форма списка

Insert → тип **Форма списка**, имя `ФормаСписка`. Лишнюю колонку: правая кнопка мыши по колонке в дереве элементов → **Удалить**. Основная форма списка — вкладка **Формы** объекта. Для дерева: таблица списка → палитра → **Отображение** = `Дерево`.

### Форма документа

Так же, тип **Форма документа**, имя `ФормаДокумента`. Стандартные кнопки «Провести и закрыть», «Записать», «Провести» появятся сами.

После каждой формы — сохранить и обновить.

## 14. Форма Организации

1. Справочник `Организации` → Формы → Insert → форма элемента `ФормаЭлемента`.
2. Поля сверху вниз: ТипОрганизации (переключатель), Код, Наименование, ИНН, Руководитель, ДолжностьРуководителя, ГлавныйБухгалтер.
3. Имя элемента бухгалтера в палитре должно быть `ГлавныйБухгалтер`. Если другое — переименуйте элемент.
4. Поле ТипОрганизации → события → ПриИзменении → лупа.
5. Кнопка **Модуль**. Замените модуль формы целиком:

```
&НаКлиенте
Процедура ПриОткрытии(Отказ)
	УстановитьВидимостьГлавногоБухгалтера();
КонецПроцедуры

&НаКлиенте
Процедура ТипОрганизацииПриИзменении(Элемент)
	УстановитьВидимостьГлавногоБухгалтера();
КонецПроцедуры

&НаКлиенте
Процедура УстановитьВидимостьГлавногоБухгалтера()
	ЭтоЮрЛицо = Объект.ТипОрганизации
		= ПредопределенноеЗначение("Перечисление.ТипыОрганизаций.ЮридическоеЛицо");
	Элементы.ГлавныйБухгалтер.Видимость = ЭтоЮрЛицо;
КонецПроцедуры
```

Если платформа создала пустую `ПриСозданииНаСервере` — оставьте пустой или удалите вызов из неё. Не создавайте вторую `ТипОрганизацииПриИзменении`.

Форма списка: колонки Тип организации, Наименование, ИНН, Код. Назначьте основной формой списка.

Проверка в предприятии: переключите тип на ИП — главный бухгалтер исчезает. Верните юридическое лицо. Реквизит не удаляйте, меняется только видимость.

## 15. Форма пород

Событие ВидПитомца → ПриИзменении:

```
&НаКлиенте
Процедура ВидПитомцаПриИзменении(Элемент)

		Объект.Родитель = ПредопределенноеЗначение("Справочник.ПородыПитомцев.Собаки");

КонецПроцедуры
```

## 16. Форма контрагентов

Нужны **страницы**. Страницы — группа элементов, у которой **Вид** = `Страницы`.

1. В дереве элементов формы: **Добавить** → **Группа** → вид **Страницы**.
2. Внутри две группы вида **Страница**: `СтраницаОсновное` (заголовок «Основное») и `СтраницаДоговоры` (заголовок «Договоры»).
3. Перетащите поля на нужную страницу.

Сверху на Основном: **ТипКонтрагента** — переключатель Клиент / Поставщик.

Если тип = Клиент, видны: Код; Наименование с заголовком **Ф.И.О. клиента**; Контактный телефон; Дата рождения; Пол; Источник; таблица Питомцы (Вид, Порода, Кличка, Дата рождения); Комментарий.

Если тип = Поставщик, видны: Код; Наименование; Контактный телефон; Основной договор; Комментарий. Поля клиента скрывает код, реквизиты из справочника не удаляйте.

Страница Договоры: реквизит формы (не справочника) имя `ДоговорыКонтрагента`, тип **ДинамическийСписок**, основная таблица `Справочник.ДоговорыКонтрагентов`, отбор владелец = `Объект.Ссылка`. Список доступен после записи элемента.

Имена элементов `ДатаРождения`, `Пол`, `Источник`, `Питомцы`, `ОсновнойДоговор`, `Наименование` должны совпасть с кодом.

```
&НаСервере
Процедура ПриСозданииНаСервере(Отказ, СтандартнаяОбработка)
	НастроитьФормуПоТипу();
КонецПроцедуры

&НаКлиенте
Процедура ТипКонтрагентаПриИзменении(Элемент)
	НастроитьФормуПоТипу();
	Если Объект.ТипКонтрагента = ПредопределенноеЗначение("Перечисление.ТипыКонтрагентов.Клиент") Тогда
		Объект.Родитель = ПредопределенноеЗначение("Справочник.Контрагенты.Клиенты");
	Иначе
		Объект.Родитель = ПредопределенноеЗначение("Справочник.Контрагенты.Поставщики");
	КонецЕсли;
КонецПроцедуры

&НаСервере
Процедура НастроитьФормуПоТипу()
	ЭтоКлиент = Объект.ТипКонтрагента = Перечисления.ТипыКонтрагентов.Клиент;
	Элементы.ДатаРождения.Видимость = ЭтоКлиент;
	Элементы.Пол.Видимость = ЭтоКлиент;
	Элементы.Источник.Видимость = ЭтоКлиент;
	Элементы.Питомцы.Видимость = ЭтоКлиент;
	Элементы.ОсновнойДоговор.Видимость = Не ЭтоКлиент;
	Если ЭтоКлиент Тогда
		Элементы.Наименование.Заголовок = "Ф.И.О. клиента";
	Иначе
		Элементы.Наименование.Заголовок = "Наименование";
	КонецЕсли;
КонецПроцедуры
```

Форма списка: **Отображение** = `Дерево`. Колонки: Наименование, Код, Тип контрагента, Контактный телефон, Дата рождения клиента, Пол, Договор, Источник, Комментарий.

## 17. Форма договоров

Поле **Наименование** только для просмотра: элемент → палитра → **ТолькоПросмотр** = Да.

Поля сверху вниз: Код, Наименование, Владелец, Номер договора, Дата заключения и Действует до в одной горизонтальной группе, Бессрочный, Комментарий.

Горизонтальная группа: **Добавить** → группа вида **Обычная группа**, группировка **Горизонтальная**, перетащите в неё оба поля дат.

Имя элемента «Действует до» должно быть `СрокДействия`. Если мастер назвал иначе — переименуйте.

События ПриИзменении: НомерДоговора и ДатаЗаключения вызывают `СформироватьНаименование`; Бессрочный вызывает `НастроитьСрок`.

```
&НаКлиенте
Процедура ПриОткрытии(Отказ)
	СформироватьНаименование();
	НастроитьСрок();
КонецПроцедуры

&НаКлиенте
Процедура НомерДоговораПриИзменении(Элемент)
	СформироватьНаименование();
КонецПроцедуры

&НаКлиенте
Процедура ДатаЗаключенияПриИзменении(Элемент)
	СформироватьНаименование();
КонецПроцедуры

&НаКлиенте
Процедура БессрочныйПриИзменении(Элемент)
	НастроитьСрок();
КонецПроцедуры

&НаКлиенте
Процедура СформироватьНаименование()
	Если ПустаяСтрока(Объект.НомерДоговора) Или Не ЗначениеЗаполнено(Объект.ДатаЗаключения) Тогда
		Возврат;
	КонецЕсли;
	Объект.Наименование = "№ " + Объект.НомерДоговора
		+ " от " + Формат(Объект.ДатаЗаключения, "ДФ=dd.MM.yyyy") + " г.";
КонецПроцедуры

&НаКлиенте
Процедура НастроитьСрок()
	Элементы.СрокДействия.Видимость = Не Объект.Бессрочный;
	Если Объект.Бессрочный Тогда
		Объект.СрокДействия = Дата(1, 1, 1);
	КонецЕсли;
КонецПроцедуры
```

Форма списка: Наименование, Владелец, Номер, даты. Назначьте основной формой списка.

## 18. Формы номенклатуры и сотрудников

### Номенклатура

Форма элемента: Код, Тип номенклатуры (переключатель), Наименование, Родитель.

```
&НаКлиенте
Процедура ТипНоменклатурыПриИзменении(Элемент)
	Если Объект.ТипНоменклатуры = ПредопределенноеЗначение("Перечисление.ТипыНоменклатуры.Услуга") Тогда

		Объект.Родитель = ПредопределенноеЗначение("Справочник.Номенклатура.Товары");
	ИначеЕсли Объект.ТипНоменклатуры = ПредопределенноеЗначение("Перечисление.ТипыНоменклатуры.Материал") Тогда
		Объект.Родитель = ПредопределенноеЗначение("Справочник.Номенклатура.Материалы");
	КонецЕсли;
КонецПроцедуры
```

Форма списка: наименование, код, тип.

### Сотрудники

Форма элемента: Таб.№, Ф.И.О. (только просмотр), Фамилия, Имя, Отчество, Пол, Дата рождения, Должность, Контактный телефон.

Поле Ф.И.О. — стандартное **Наименование**. **ТолькоПросмотр** = Да.

События ПриИзменении у Фамилия, Имя, Отчество:

```
&НаКлиенте
Процедура ФамилияПриИзменении(Элемент)
	СобратьФИО();
КонецПроцедуры

&НаКлиенте
Процедура ИмяПриИзменении(Элемент)
	СобратьФИО();
КонецПроцедуры

&НаКлиенте
Процедура ОтчествоПриИзменении(Элемент)
	СобратьФИО();
КонецПроцедуры

&НаКлиенте
Процедура СобратьФИО()
	Объект.Наименование = СокрЛП(Объект.Фамилия + " " + Объект.Имя + " " + Объект.Отчество);
КонецПроцедуры
```

Форма выбора (отдельная, имя `ФормаВыбора`): колонки Таб.№, Ф.И.О., Должность. На вкладке **Формы** справочника **Основная форма выбора** = эта форма.

Форма списка: Таб.№, Ф.И.О., Должность, Дата рождения, Контактный телефон.

### Пользователи

Основную форму элемента можно оставить сгенерированной: Идентификатор, Имя пользователя. Кнопки создания у оператора убирает **роль** (шаг 21), а не удаление кнопки с формы администратора.

## 19. Формы документов

### 19.1. Запись клиента

1. Документ `ЗаписьКлиента` → Формы → Insert → **Форма документа**.
2. Страницы: группа вида Страницы, две страницы **Основное** и **Заказы клиентов**.
3. Шапка в две колонки: обычная группа с горизонтальной группировкой.

Расположение:

- Номер | поле «От» = Дата
- Сотрудник | рядом нередактируемое поле Должность
- Клиент | рядом № телефона
- Дата записи
- табличная часть Услуги: Услуга, Стоимость
- внизу Комментарий | Ответственный

Поля **Должность** и **№ телефона** — это **не** реквизиты документа. Окно **Реквизиты** редактора формы (не дерево конфигурации) → правая кнопка мыши по корню реквизитов формы → **Добавить**:

- имя `ДолжностьСотрудника`, тип ссылка на `Должности`;
- имя `ТелефонКлиента`, тип Строка, длина 20.

Перетащите их на форму рядом с Сотрудник и Клиент. **ТолькоПросмотр** = Да.

Модуль формы. Строки с `ПараметрыСеанса` заработают после шага 20; до этого их можно временно закомментировать, затем вернуть.

```
&НаСервере
Процедура ПриСозданииНаСервере(Отказ, СтандартнаяОбработка)
	Если Не ЗначениеЗаполнено(Объект.Ссылка) Тогда
		Объект.Ответственный = ПараметрыСеанса.ТекущийПользователь;
	КонецЕсли;
	ЗаполнитьПоляПросмотра();
КонецПроцедуры

&НаСервере
Процедура ЗаполнитьПоляПросмотра()
	Если ЗначениеЗаполнено(Объект.Сотрудник) Тогда
		ДолжностьСотрудника = Объект.Сотрудник.Должность;
	Иначе
		ДолжностьСотрудника = Справочники.Должности.ПустаяСсылка();
	КонецЕсли;
	Если ЗначениеЗаполнено(Объект.Клиент) Тогда
		ТелефонКлиента = Объект.Клиент.КонтактныйТелефон;
	Иначе
		ТелефонКлиента = "";
	КонецЕсли;
КонецПроцедуры

&НаКлиенте
```

Проверьте автозаполнение: основание, клиент, сотрудник, две услуги. Для макета учебного задания можно оставить одну услугу «Стрижка креативная» 1500 (удалите чистку ушей, как на скриншоте) либо обе. Дальше в таблице ниже — вариант макета: услуга 1500 + товар 500 = 2000.

Дата 10.08.2023 12:00:00. Склад Витрина. Комментарий: `Стрижка Болонки, для выставки`.

Вкладка Товары: Гипоаллергенный шампунь-бальзам Well room 400 мл., количество 1, цена 500, сумма 500.

Запишите. Сумма документа **2000,00**. Проведите.

Проверки:

- Товары на складах: расход 1 шампуня с Витрины.
- Продажи: строки услуги и товара.
- Заказы клиентов: сумма факт равна итогу услуг, запись клиента = основание. Если основание пустое — факта быть не должно.
- Печать: заголовок, таблицы услуг и товаров, сумма, ответственный.

Вторая реализация **без товаров** (на основании Черепановой, услуга 1200, склад Витрина): таблица товаров на печати не выходит.

Третья реализация без основания: клиент Соколов, сотрудник Лисицына, Чистка ушей 500, антибактериальный шампунь 2 × 900 = 1800. В заказах клиентов движений нет.

### 23.12. Сценарий роли оператора

1. Выйдите из предприятия.
2. Войдите как **Оператор**.
3. Настройки → Пользователи: кнопки **Создать** нет.
4. Создайте новую запись клиента: Ответственный = Оператор салона (элемент справочника создался при входе).
5. Войдите снова как Мазаева: кнопка Создать в пользователях есть.

### 23.13. Сценарий опции складов

Настройки → Использовать склады. Снимите флажок, перезайдите. Должны скрыться справочник Склады, поле Склад в документах, регистр Товары на складах. Верните флажок перед сдачей, если в демонстрационных данных нужны складские движения.

### Как выгрузить

1. Закройте окно **1С:Предприятие**, Конфигуратор оставьте.
2. Меню **Администрирование** → **Выгрузить информационную базу**.
3. Папка любая, например Рабочий стол.
4. Имя файла целиком: `КибальникСА_Спринт2_ГрумингСалон.dt`
5. **Сохранить**. Дождитесь «Выгрузка информационной базы в файл … завершена» → **ОК**.
6. В проводнике Windows: правая кнопка мыши по этому `.dt` → **Отправить** → **Сжатая ZIP-папка**.
