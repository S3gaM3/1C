# 1С:Груминг салон

Пошаговая инструкция: оба спринта курса подряд **в одной и той же** информационной базе, в Конфигураторе учебной платформы **1С:Предприятие 8.3**. Не собирайте сдачу кодом в других средах.

## Ваша программа (как на экране «О программе»)

Работайте только в этой установке. Другую платформу и вторую базу не заводите.

| Что на экране **Справка → О программе** | Как должно быть |
| --- | --- |
| Платформа | **1С:Предприятие 8.3 (8.3.27.2130)**, подпись «Версия для разработчиков» |
| Конфигурация | **1С:Груминг салон** |
| Разработчик (поставщик) | **Кибальник Сергей Андреевич** |
| Наименование базы в списке | **Груминг салон** |
| Режим | **Файловый** |
| Каталог | `C:\Users\user\Documents\1C\GroomingSalon` |
| Приложение | **Конфигуратор** |
| Локализация | информационная база русский (Россия), сеанс русский (Россия) |

Как открыть: ярлык **1С:Предприятие** → в списке баз строка **Груминг салон** → справа кнопка **Конфигуратор**. Кнопку **1С:Предприятие** нажимайте только когда нужно вводить данные.

Если версия конфигурации в «О программе» уже `2.0.0.5` — это та же база, новую не создавайте. Перед каждой выгрузкой поставьте номер версии из таблицы сдачи ниже.

## Оба спринта в один заход

Курс принимает **две** выгрузки из **одной** базы. Порядок нельзя менять: ревьюер спринта 1 ищет код **конструктора** (два цикла по товарам). Ревьюер спринта 2 ищет **один** цикл. Если сначала склеить циклы, первую сдачу уже не собрать.

1. [docs/00-podgotovka.md](docs/00-podgotovka.md) — открыть вашу файловую базу, проверить свойства корня.
2. [docs/01-sprint-1.md](docs/01-sprint-1.md) — объекты, конструктор движений, печать, опция складов. Формы и роли пока не рисуйте.
3. [docs/03-dannye.md](docs/03-dannye.md) — ввести справочники и провести документы (через **Все функции**).
4. [docs/04-sdacha.md](docs/04-sdacha.md) — версия `1.0.0.1`, выгрузка спринта 1 в ZIP. Конструктор в модуле реализации не трогать.
5. Сразу [docs/02-sprint-2.md](docs/02-sprint-2.md) — в той же базе: формы, один цикл проведения, заказы, параметр сеанса, роли, подсистемы. Версия `2.0.0.1`.
6. Снова данные и проверки из файла 03 (роли, склады, печать без пустых таблиц).
7. Снова файл 04 — выгрузка спринта 2.

Внутри файлов каждый пункт — куда нажать в Конфигураторе 8.3.27 и что вписать. Сокращений вроде «ПКМ», «ТЧ», «ТЗ», «15.2» нет. Имена объектов (`ЗаписьКлиента`, `Отбор.Владелец`) копируйте как есть.
