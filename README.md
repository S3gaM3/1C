# 1С:Груминг салон

Пошаговая инструкция для полного новичка: как собрать учебную конфигурацию **в Конфигураторе 1С:Предприятие**, а не кодом в других средах.

Курс проверяет не только набор объектов, но и то, что вы сами применяете приёмы из уроков. Файл `.dt` нужно получить **своими руками** в Конфигураторе. Эта папка — конспект «куда нажать» и «что вписать в поля».

## Как пользоваться

Идите по файлам строго по порядку. Не перескакивайте на спринт 2, пока не проведены документы спринта 1.

| Файл | Зачем |
| --- | --- |
| [docs/00-podgotovka.md](docs/00-podgotovka.md) | Создать пустую базу, свойства конфигурации, язык Русский |
| [docs/01-sprint-1.md](docs/01-sprint-1.md) | Справочники, документы, регистры, функционал складов, движения конструктором |
| [docs/02-sprint-2.md](docs/02-sprint-2.md) | Формы по макетам, проведение в одном цикле, печать, роли, подсистемы |
| [docs/03-dannye.md](docs/03-dannye.md) | Готовые значения для вставки в карточки и документы |
| [docs/04-sdacha.md](docs/04-sdacha.md) | Чек-лист и выгрузка `.dt` в ZIP |

## Что сдавать

- Спринт 1: `ФамилияИнициалы_Спринт1_ГрумингСалон.dt` в ZIP, версия `1.0.0.1`
- Спринт 2: `ФамилияИнициалы_Спринт2_ГрумингСалон.dt` в ZIP, версия `2.0.0.1`

Имя конфигурации — `ГрумингСалон`. Синоним — `1С:Груминг салон`. Поставщик — ваши фамилия и имя.
