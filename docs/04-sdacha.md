# 4. Чек-лист и сдача

## Спринт 1

Версия конфигурации `1.0.0.1`. Имя `ГрумингСалон`, синоним `1С:Груминг салон`, поставщик — ваши фамилия и имя, вариант встроенного языка — Русский.

- [ ] Все справочники, перечисления, документы, регистры из учебного задания есть
- [ ] Предопределённые группы: Кошки, Собаки, Клиенты, Поставщики
- [ ] Договоры подчинены контрагентам (вкладка Владельцы, использование подчинения — элементам)
- [ ] Движения поступления и реализации построены **конструктором**, а не написаны с нуля руками
- [ ] Печатная форма реализации открывается
- [ ] Константа и функциональная опция складов, связанные объекты в составе опции
- [ ] Ответственный в трёх документах есть (пока можно выбирать вручную)
- [ ] В предприятии заведены демонстрационные данные, документы проведены
- [ ] Программный код на русском

### Как выгрузить файл `.dt`

После того как в предприятии всё проверили:

1. Закройте режим 1С:Предприятие, оставьте Конфигуратор.
2. Меню **Администрирование** → **Выгрузить информационную базу**.
3. Папка: любая, например `Рабочий стол\Выгрузки`.
4. **Имя файла** наберите целиком, расширение `.dt`:

`ФамилияИнициалыСтудента_Спринт1_ГрумингСалон.dt`

Пример из учебного задания: `ГагаринЮА_Спринт1_ГрумингСалон.dt`. Если вы Кибальник Сергей: `КибальникС_Спринт1_ГрумингСалон.dt`.

5. Нажмите **Сохранить**. Дождитесь окна «Выгрузка информационной базы в файл … завершена» → **ОК**.
6. В проводнике Windows нажмите **правую кнопку мыши** по этому файлу `.dt` → **Отправить** → **Сжатая ZIP-папка** (или архиватор 7-Zip). Имя архива **то же**, только расширение `.zip`.
7. В форму сдачи курса перетащите **ZIP**, не `.dt` и не ссылку на Google Диск. Если архив больше 10 МБ — напишите куратору.

Не выгружайте «конфигурацию в файл cf». В учебном задании нужна именно **информационная база** (файл `.dt`): внутри будут и объекты, и ваши демонстрационные данные.

## Спринт 2

Смените версию на `2.0.0.1` (корень конфигурации → палитра свойств → **Версия**). Имя файла выгрузки: `ФамилияИнициалыСтудента_Спринт2_ГрумингСалон.dt`. Дальше те же шаги выгрузки, что в спринте 1.

- [ ] Формы элементов, списков и выбора совпадают с макетами (переключатели, колонки, страницы)
- [ ] Главный бухгалтер виден только у юридического лица
- [ ] Наименование договора собирается программно, срок скрыт если бессрочный
- [ ] ФИО сотрудника собирается программно и заблокировано
- [ ] Сумма реализации считается при записи, поле только просмотр
- [ ] Один цикл по табличной части Товары для склада и продаж
- [ ] Заказы клиентов: план от записи, факт от реализации с основанием
- [ ] Пустые табличные части не печатаются
- [ ] Панель навигации документов ведёт к регистрам
- [ ] Параметр сеанса, автосоздание пользователя, автор подставляется сам
- [ ] Две роли, у второй нет интерактивного создания пользователей
- [ ] Подсистемы и начальная страница как в макете: журнал записей
- [ ] Не созданы объекты, которых нет в учебном задании

---

## Чего не делать

Не собирайте файл `.dt` генераторами и не сдавайте веб-клон интерфейса 1С. Ревьюер открывает вашу базу в Конфигураторе и смотрит дерево объектов, модули и формы.

Не добавляйте «от себя» отчёты, обработки, лишние подсистемы и кнопки.

Если тип реквизита в учебном задании стоит как «?», выберите его по смыслу, как в уроках:

- ИНН — строка, длина 12;
- суммы, цены, стоимость — Число, длина 15, точность 2;
- количество — Число, длина 15, точность 3;
- наименование номенклатуры — 100 символов.
