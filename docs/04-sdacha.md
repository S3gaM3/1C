# 4. Чек-лист и сдача

## Спринт 1

Версия `1.0.0.1`. Имя `ГрумингСалон`, синоним `1С:Груминг салон`, поставщик — ваши фамилия и имя, язык Русский.

- [ ] Все справочники, перечисления, документы, регистры из ТЗ есть
- [ ] Предопределённые группы: Кошки, Собаки, Клиенты, Поставщики
- [ ] Договоры подчинены контрагентам
- [ ] Движения поступления и реализации построены **конструктором**
- [ ] Печатная форма реализации открывается
- [ ] Константа + функциональная опция складов, связанные объекты в составе опции
- [ ] Ответственный в трёх документах есть (пока можно выбирать вручную)
- [ ] В предприятии заведены демо-данные, документы проведены
- [ ] Программный код на русском

Выгрузка: Конфигуратор → **Администрирование** → **Выгрузить информационную базу**. Имя файла:

`ФамилияИнициалыСтудента_Спринт1_ГрумингСалон.dt`

Пример из ТЗ: `ГагаринЮА_Спринт1_ГрумингСалон.dt`.

Этот `.dt` положите в ZIP **с тем же именем**. В форму сдачи отправляйте ZIP, не голый `.dt` и не ссылку на диск. Если ZIP больше 10 МБ — напишите куратору.

## Спринт 2

Смените версию на `2.0.0.1`. Имя файла: `ФамилияИнициалыСтудента_Спринт2_ГрумингСалон.dt`.

- [ ] Формы элементов, списков и выбора совпадают с макетами (переключатели, колонки, страницы)
- [ ] Главный бухгалтер только у юрлица
- [ ] Наименование договора авто, срок скрыт если бессрочный
- [ ] ФИО сотрудника авто и заблокировано
- [ ] Сумма реализации считается при записи, поле только просмотр
- [ ] Один цикл по ТЧ Товары для склада и продаж
- [ ] Заказы клиентов: план от записи, факт от реализации с основанием
- [ ] Пустые ТЧ не печатаются
- [ ] Панель навигации документов ведёт к регистрам
- [ ] Параметр сеанса, автосоздание пользователя, автор подставляется сам
- [ ] Две роли, у второй нет интерактивного создания пользователей
- [ ] Подсистемы и начальная страница как в макете: журнал записей
- [ ] Не созданы объекты, которых нет в ТЗ

## Чего не делать

Не собирайте `.dt` генераторами и не сдавайте веб-клон интерфейса 1С. Ревьюер открывает вашу базу в Конфигураторе и смотрит дерево объектов, модули и формы.

Не добавляйте «от себя» отчёты, обработки, лишние подсистемы и кнопки.

Если тип реквизита в ТЗ стоит как «?», выберите его по смыслу, как в уроках: ИНН — строка, суммы — 15.2, количество — 15.3, наименование номенклатуры — 100 символов.
