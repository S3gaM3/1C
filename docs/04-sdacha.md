# 4. Чек-лист и две выгрузки из одной базы

Обе сдачи — из каталога `C:\Users\user\Documents\1C\GroomingSalon`, платформа **8.3.27.2130**, Конфигуратор. Сначала выгрузка спринта 1, сразу затем файл 02 и выгрузка спринта 2. **Не** делайте вторую информационную базу.

Имя в файлах сдачи: `КибальникСА` (Кибальник Сергей Андреевич). Поставщик в корне: `Кибальник Сергей Андреевич`. Синоним конфигурации: `1С:Груминг салон`. Язык: Русский.

## Выгрузка 1 — после файла 01 и данных

Версия в палитре корня **обязательно** `1.0.0.1` (если в «О программе» стоит 2.0.0.5 — сначала верните 1.0.0.1, сохраните конфигурацию).

- [ ] Все справочники, перечисления, документы, регистры из учебного задания спринта 1 есть
- [ ] Предопределённые группы: Кошки, Собаки, Клиенты, Поставщики
- [ ] Договоры подчинены контрагентам (вкладка Владельцы, элементам)
- [ ] В модуле реализации **два** цикла по товарам и комментарии `//{{__КОНСТРУКТОР_ДВИЖЕНИЙ_РЕГИСТРОВ`
- [ ] В модуле поступления — приход на склад конструктором
- [ ] Печатная форма реализации открывается
- [ ] Константа и функциональная опция складов
- [ ] Ответственный в трёх документах есть
- [ ] Демонстрационные данные введены, документы проведены
- [ ] Программный код на русском

### Как выгрузить `.dt` в 8.3.27 (файловый режим)

1. Закройте окно **1С:Предприятие**, Конфигуратор оставьте.
2. Меню **Администрирование** → **Выгрузить информационную базу**.
3. Папка любая, например Рабочий стол.
4. Имя файла целиком:

`КибальникСА_Спринт1_ГрумингСалон.dt`

5. **Сохранить**. Дождитесь «Выгрузка информационной базы в файл … завершена» → **ОК**.
6. В проводнике Windows: правая кнопка мыши по этому `.dt` → **Отправить** → **Сжатая ZIP-папка**. Имя архива то же, расширение `.zip`.
7. В форму курса перетащите **ZIP**.

Не выгружайте «конфигурацию в файл» (получится `.cf`). Нужна именно информационная база `.dt`.

Сразу после этой выгрузки **не закрывайте** базу: откройте [02-sprint-2.md](02-sprint-2.md), поставьте версию `2.0.0.1` и продолжайте.

## Чего не делать

Не собирайте `.dt` генераторами и не сдавайте веб-клон. Ревьюер откроет выгрузку в Конфигураторе 8.3.

Не добавляйте отчёты, обработки и лишние кнопки.

Не создавайте вторую базу «для спринта 2»: обе выгрузки должны быть историей одной папки `C:\Users\user\Documents\1C\GroomingSalon`.

Если тип реквизита в учебном задании стоит как «?»:

- ИНН — строка, длина 12;
- суммы, цены, стоимость — Число, длина 15, точность 2;
- количество — Число, длина 15, точность 3;
- наименование номенклатуры — 100 символов.
