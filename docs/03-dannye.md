# 3. Данные для вставки в формы

Вводите в режиме **1С:Предприятие** (из окна списка баз кнопка **1С:Предприятие**, не Конфигуратор), под пользователем с полными правами.

Коды можно оставить автонумерации. Если номер уехал — не страшно.

### Как открыть справочник, пока нет подсистем спринта 2

1. В предприятии откройте меню (кружок 1С слева сверху или **Сервис**).
2. Если нет **Все функции**: **Сервис** → **Параметры** → флажок **Отображать команду «Все функции»** → ОК, перезайдите в меню.
3. **Все функции** → **Справочники** → нужное имя (Должности, Сотрудники…).
4. Кнопка **Создать**. Заполните поля из таблиц ниже → **Записать и закрыть**.

Документы: **Все функции** → **Документы** → Запись клиента / Реализация / Поступление. После заполнения **Провести и закрыть**.

Порядок заведения: должности → сотрудники → склады, источники, породы, номенклатура → контрагенты → договоры → организация → документы.

## 3.13. Реализация на основании записи

В журнале записей встаньте на запись Летяевой → **Создать на основании** → Реализация товаров и услуг.

Проверьте автозаполнение: основание, клиент, сотрудник, две услуги (стрижка 1500 и чистка 500). Для макета ТЗ **оставьте одну услугу** «Стрижка креативная» 1500 (удалите чистку ушей, как на скриншоте) либо оставьте обе — макет показывает одну строку услуг.

Допишите:

| Поле | Вписать |
| --- | --- |
| Дата | 10.08.2023 12:00:00 |
| Склад | Витрина |
| Комментарий | Стрижка Болонки, для выставки |

Вкладка Товары:

| Товар | Количество | Цена | Сумма |
| --- | --- | --- | --- |
| Гипоаллергенный шампунь-бальзам Well room 400 мл. | 1 | 500 | 500 |

Запишите (не обязательно жать пересчёт суммы вручную). Сумма документа: **2000,00**. Проведите.

Проверки:

- Регистр Товары на складах: расход 1 шампуня с Витрины.
- Регистр Продажи: две строки (услуга 1500 и товар 500) либо как получилось по ТЧ.
- Регистр Заказы клиентов: сумма факт 1500 (итог услуг), запись клиента = основание. Если основание пустое — факта быть не должно.

Печать: заголовок «Реализация товаров и услуг», таблицы услуг и товаров, сумма 2000, ответственный Мазаева Ангелина. Сделайте вторую реализацию **без товаров** и убедитесь, что таблица товаров на печати не выходит.

Ещё реализации:

- На основании записи Черепановой: только услуга 1200, без товаров, склад Витрина.
- Без основания: клиент Соколов, сотрудник Лисицына, услуга Чистка ушей 500, товар антибактериальный шампунь 2 × 900 = 1800. У этой реализации в заказах клиентов движений нет.

## 3.14. Сценарий роли без добавления пользователей

1. Выйдите.
2. Войдите как **Оператор**.
3. Откройте Настройки → Пользователи: кнопки **Создать** нет.
4. Создайте новую запись клиента: **Ответственный** = Оператор салона (элемент справочника создался при входе).
5. Войдите снова как Мазаева: Создать в пользователях есть.

---

## 3.15. Сценарий опции складов

Настройки → Использовать склады. Снимите флажок, обновите интерфейс (перезайдите).

Должны скрыться: справочник Склады, поле Склад в документах, регистр Товары на складах.

Верните флажок перед сдачей, если в демо нужны складские движения.
