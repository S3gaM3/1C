# 0. Подготовка информационной базы

Работайте только в учебной платформе **1С:Предприятие 8.3**, режим **Конфигуратор**. Другой редактор код для сдачи не подойдёт.

## 0.1. Создать пустую базу

1. Запустите ярлык **1С:Предприятие** (окно со списком информационных баз, не сразу Конфигуратор).
2. Справа нажмите **Добавить**.
3. Точка: **Создание новой информационной базы** → **Далее**.
4. Точка: **Создание информационной базы без конфигурации для разработки новой…** → **Далее**.
5. **Наименование:** `Груминг салон` (это подпись в списке баз, не имя конфигурации).
6. **Каталог:** создайте папку, например `C:\1C\GroomingSalon\`, укажите её. Внутри платформа сама сложит файлы базы.
7. Остальные шаги мастера — **Далее** / **Готово** без смены языка и режима.
8. В списке баз выделите `Груминг салон` и нажмите **Конфигуратор** (не «1С:Предприятие»).

## 0.2. Открыть дерево и свойства конфигурации

1. Меню **Конфигурация** → **Открыть конфигурацию**. Слева появится корень с жёлтым кубиком.
2. Если корень называется просто `Конфигурация`, щёлкните его **один раз**.
3. Палитра свойств: если панели нет — **Сервис** → **Палитра свойств** или `Alt+Enter`.
4. Заполните свойства корня (щёлкайте поле, вводите, переходите к следующему):

| Свойство в палитре | Что вписать |
| --- | --- |
| Имя | `ГрумингСалон` — без пробелов |
| Синоним | `1С:Груминг салон` |
| Основной режим запуска | Управляемое приложение |
| Вариант встроенного языка | **Русский** |
| Поставщик | ваши фамилия и имя, например `Кибальник Сергей` |
| Версия | пока `1.0.0.1` |

Синоним и имя — разные поля. Имя для платформы, синоним для заголовка окна.

5. Меню **Конфигурация** → **Сохранить конфигурацию** (`Ctrl+S`).
6. Меню **Конфигурация** → **Обновить конфигурацию базы данных** (`F7`).
7. В окне «Реорганизация информации» нажмите **Принять** / **Выполнить**. Если спрашивает про монопольный режим — согласитесь.

Пока не запускайте предприятие: объектов ещё нет.

## 0.3. Три панели, без которых ничего не найти

- **Дерево конфигурации** — слева. Ветки: Общие, Справочники, Документы, Перечисления, Регистры накопления…
- **Окно объекта** — большое, с вкладками Данные, Формы, Нумерация. Открывается двойным щелчком по объекту.
- **Палитра свойств** — список Имя, Синоним, Тип. Показывает свойства того, что сейчас выделено.

Всегда смотрите заголовок палитры: «Справочник Сотрудники» это свойства всего справочника, «Реквизит Фамилия» — уже одного поля.

## 0.4. Как добавлять любой объект

1. В дереве ПКМ по **нужной ветке** (Справочники, Документы, Перечисления…) → **Добавить**.
2. Сразу в палитре задайте **Имя** (без пробелов, как в инструкции) и **Синоним** (с пробелами, для пользователя).
3. Свои поля — только вкладка **Данные**, зелёный **+** над таблицей реквизитов. Это не «стандартные реквизиты».
4. После пачки объектов: `Ctrl+S`, затем `F7`, в диалоге **Принять**.

## 0.5. Как задать тип реквизита

1. Выделите реквизит в таблице на вкладке **Данные**.
2. В палитре свойств найдите **Тип**, нажмите кнопку с **T** или лупу.
3. В окне «Тип данных»:
   - одна галочка слева (Строка / Число / Дата / Булево / СправочникСсылка / ПеречислениеСсылка / ДокументСсылка);
   - справа уточнение: длина строки, точность числа, какой справочник.
4. **ОК**.

Частые типы:

| Нужно | Как щёлкнуть в окне типа |
| --- | --- |
| ИНН | Строка, длина 12 |
| Телефон | Строка, длина 20 |
| Комментарий | Строка, длина 0 (неограниченная) |
| Наименование номенклатуры | длина наименования справочника = 100, вкладка Данные самого справочника |
| Сумма, цена, стоимость | Число, длина 15, точность 2 |
| Количество | Число, длина 15, точность 3 |
| Дата рождения | Дата, состав **Дата** |
| Дата документа, дата записи | Дата, состав **Дата и время** |
| Флажок | Булево |
| Выбор из справочника | слева СправочникСсылка, справа нужный справочник |
| Выбор из перечисления | слева ПеречислениеСсылка, справа нужное перечисление |
| Основание — другой документ | слева ДокументСсылка, справа ЗаписьКлиента |

Обязательное поле: палитра реквизита → **Проверка заполнения** = **Выдавать ошибку**.

### Что значит «Число 15.2» и «Число 15.3»

Это **не** значение 15,2. Это два числа в окне типа **Число**:

| Запись в инструкции | Длина | Точность | Зачем |
| --- | --- | --- | --- |
| Число 15.2 | `15` | `2` | деньги: сумма, цена, стоимость |
| Число 15.3 | `15` | `3` | количество (1,000 как в макете ТЗ) |

**Длина 15** — сколько цифр всего (до запятой + после).  
**Точность 2** — сколько знаков **после запятой**. Для денег: `1500,00`. Для количества: точность 3 → `10,000`.

Как выставить:

1. Реквизит выделен → свойство **Тип** → кнопка **T**.
2. Слева галочка только на **Число** (снимите Строка, если стояла).
3. Справа появятся поля **Длина** и **Точность** (не «длина строки»).
4. Для суммы: длина `15`, точность `2`. Для количества: длина `15`, точность `3`.
5. **Неотрицательное** можно включить.
6. **ОК**. В палитре тип станет выглядеть как `Число(15, 2)`.

## 0.6. Стандартные реквизиты Код и Наименование

Их не создают плюсом. Чтобы сменить подпись (Таб.№, Ф.И.О., Порода): выделить объект в дереве → палитра → строка **Стандартные реквизиты** → лупа → дважды Код или Наименование → свойство **Синоним**. Подробный разбор — в `01-sprint-1.md`, раздел 1.3.

Дальше откройте [01-sprint-1.md](01-sprint-1.md) и идите по порядку: сначала все перечисления, потом справочники.
