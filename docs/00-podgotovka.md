# 0. Подготовка информационной базы

Работайте только в учебной платформе **1С:Предприятие 8.3** (режим **Конфигуратор**). Другие языки и редакторы для сдачи не подходят.

## 0.1. Создать пустую базу

1. Запустите ярлык **1С:Предприятие**.
2. Нажмите **Добавить**.
3. Выберите **Создание новой информационной базы** → **Далее**.
4. Выберите **Создание информационной базы без конфигурации…** → **Далее**.
5. Имя в списке баз: `Груминг салон`.
6. Каталог базы создайте отдельно, например `C:\1C\GroomingSalon\`.
7. Готово. В списке баз выделите новую строку и нажмите **Конфигуратор**.

## 0.2. Открыть дерево конфигурации

В Конфигураторе: меню **Конфигурация** → **Открыть конфигурацию**. Слева появится корень **Конфигурация**.

ПКМ по корню → **Свойства** (или `Alt+Enter`). Заполните:

| Свойство | Значение |
| --- | --- |
| Имя | `ГрумингСалон` |
| Синоним | `1С:Груминг салон` |
| Основной режим запуска | Управляемое приложение |
| Вариант встроенного языка | **Русский** |
| Поставщик | ваши фамилия и имя, например `Кибальник Сергей` |
| Версия (спринт 1) | `1.0.0.1` |
| Версия (после спринта 2) | `2.0.0.1` |

Проверьте, что **модуль обычного приложения** не нужен: сдаёте управляемое приложение (Taxi).

Сохраните: **Конфигурация** → **Сохранить конфигурацию** (`Ctrl+S`), затем **Конфигурация** → **Обновить конфигурацию базы данных** (`F7`). Согласитесь с реструктуризацией.

## 0.3. Как добавлять объекты (запомните навсегда)

1. В дереве раскройте нужную ветку (**Справочники**, **Документы**, **Перечисления** и т.д.).
2. ПКМ по ветке → **Добавить**.
3. В палитре свойств сразу задайте **Имя** (без пробелов, латиница недопустима — только русский идентификатор, как в уроках) и **Синоним** (как в интерфейсе).
4. Реквизиты: на вкладке **Данные** нажмите **Добавить** (иконка «+» над списком реквизитов).
5. После группы объектов всегда `Ctrl+S` и `F7`.

Имена ниже — рабочие. Синонимы должны совпадать с макетами ТЗ.

## 0.4. Типы, которые вы будете выбирать часто

| Что в ТЗ | Тип в палитре |
| --- | --- |
| Строка произвольная | Строка, переменная длина, 0 (неограниченная) |
| ИНН | Строка, 12 |
| Телефон | Строка, 20 |
| Наименование номенклатуры | Строка, **100** (это прямо сказано в ТЗ спринта 2) |
| Сумма / цена / стоимость | Число, длина 15, точность 2, неотрицательное |
| Количество | Число, длина 15, точность 3 |
| Дата рождения, срок договора | Дата, состав **Дата** |
| Дата документа, дата записи | Дата, состав **Дата и время** |
| Признак | Булево |
| Ссылка на справочник | `СправочникСсылка.<Имя>` |
| Ссылка на документ | `ДокументСсылка.<Имя>` |
| Значение перечисления | `ПеречислениеСсылка.<Имя>` |

Обязательность: у реквизита **Проверка заполнения** = **Выдавать ошибку**, если в ТЗ колонка «Обязательный = Да».
