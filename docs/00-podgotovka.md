# 0. Подготовка информационной базы

Работайте только в учебной платформе **1С:Предприятие 8.3**, режим **Конфигуратор**. Другой редактор кода для сдачи не подойдёт: ревьюер откроет вашу базу именно в Конфигураторе.

Слова **«учебное задание»** и **«макет»** в этой инструкции означают картинки и таблицы из материалов курса Яндекс Практикум. Сокращение «ТЗ» нигде дальше не используется.

---

## 0.1. Создать пустую информационную базу

1. Запустите ярлык **1С:Предприятие**. Откроется окно со **списком информационных баз**. Это ещё не Конфигуратор и не режим работы пользователя.
2. Справа нажмите кнопку **Добавить**.
3. Поставьте точку на строке **Создание новой информационной базы**. Нажмите **Далее**.
4. Поставьте точку на строке **Создание информационной базы без конфигурации для разработки новой…**. Нажмите **Далее**.
5. Поле **Наименование:** впишите `Груминг салон`. Это только подпись в списке баз, не имя конфигурации внутри дерева.
6. Поле **Каталог:** создайте папку на диске, например `C:\1C\GroomingSalon\`, и укажите её. Внутри этой папки платформа сама сложит файлы базы. Не выбирайте папку, в которой уже лежит другая база.
7. Остальные шаги мастера оставляйте как есть. Нажимайте **Далее**, затем **Готово**. Язык и режим запуска на этом шаге не меняйте.
8. В списке баз один раз щёлкните строку `Груминг салон`, чтобы она выделилась.
9. Справа нажмите кнопку **Конфигуратор**. Кнопку **1С:Предприятие** пока не нажимайте: объектов ещё нет.

---

## 0.2. Открыть дерево и заполнить свойства конфигурации

1. В меню сверху выберите **Конфигурация** → **Открыть конфигурацию**. Слева появится дерево. Корень дерева выглядит как жёлтый кубик и сначала может называться просто `Конфигурация`.
2. Щёлкните корень **один раз**, чтобы он выделился.
3. Справа или внизу должна быть панель **Палитра свойств**. Если панели нет, откройте её: меню **Сервис** → **Палитра свойств**. Можно также выделить корень и нажать клавиши Alt и Enter.
4. В палитре свойств заполните поля по таблице. Щёлкайте поле, вводите значение, переходите к следующему.

| Свойство в палитре | Что вписать |
| --- | --- |
| Имя | `ГрумингСалон` — без пробелов, слитно |
| Синоним | `1С:Груминг салон` |
| Основной режим запуска | **Управляемое приложение** |
| Вариант встроенного языка | **Русский** |
| Поставщик | ваши фамилия и имя, например `Кибальник Сергей` |
| Версия | пока `1.0.0.1` |

**Имя** и **Синоним** — разные поля. Имя нужно платформе (без пробелов). Синоним видит пользователь в заголовке окна.

5. Сохраните конфигурацию и обновите базу данных, как в разделе 0.7 ниже.

Пока не запускайте режим 1С:Предприятие: объектов ещё нет.

---

## 0.3. Три панели, без которых ничего не найти

Запомните три окна. Дальше инструкция ссылается на них по этим именам.

**Дерево конфигурации** — слева. Ветки: Общие, Справочники, Документы, Перечисления, Регистры накопления и другие. Если дерева не видно: меню **Конфигурация** → **Открыть конфигурацию**.

**Окно объекта** — большое окно в центре. Открывается двойным щелчком по объекту в дереве. Внутри вкладки: **Данные**, **Формы**, **Нумерация**, **Иерархия**, **Владельцы**, **Прочее** и другие.

**Палитра свойств** — список свойств того, что сейчас выделено: Имя, Синоним, Тип и так далее. Всегда смотрите **заголовок** палитры:

- «Свойства: Справочник Сотрудники» — сейчас выделен весь справочник;
- «Свойства: Реквизит Фамилия» — сейчас выделено одно поле.

Если палитра показывает свойства всего справочника, а вы хотели настроить одно поле — щёлкните это поле ещё раз в таблице на вкладке **Данные**.

---

## 0.4. Как добавить любой объект

Этот рецепт одинаков для справочника, документа, перечисления и регистра.

1. В дереве конфигурации найдите нужную ветку: **Справочники**, **Документы**, **Перечисления**, **Регистры накопления** и так далее.
2. Нажмите **правую кнопку мыши** по этой ветке.
3. В меню выберите **Добавить**.
4. Сразу в палитре свойств задайте **Имя** (без пробелов, как в инструкции) и **Синоним** (с пробелами, для пользователя).
5. Свои поля добавляйте только на вкладке **Данные**, зелёной кнопкой **+** над таблицей реквизитов. Это не «стандартные реквизиты». Стандартные поля Код, Наименование, Номер, Дата платформа уже создала сама.
6. После пачки объектов сохраните конфигурацию и обновите базу данных, как в разделе 0.7.

---

## 0.5. Как задать тип реквизита

1. На вкладке **Данные** один раз щёлкните реквизит в таблице, чтобы строка подсветилась.
2. В палитре свойств найдите строку **Тип**.
3. Нажмите кнопку с буквой **T** или лупу справа от типа.
4. Откроется окно **Тип данных**:
   - слева ставьте **одну** галочку (Строка, Число, Дата, Булево, СправочникСсылка, ПеречислениеСсылка или ДокументСсылка);
   - справа уточняйте длину строки, длину и точность числа, какой именно справочник, перечисление или документ.
5. Нажмите **ОК**.

Частые типы:

| Что нужно | Как щёлкнуть в окне типа |
| --- | --- |
| ИНН | слева **Строка**, справа длина `12` |
| Телефон | слева **Строка**, справа длина `20` |
| Комментарий | слева **Строка**, справа длина `0` (неограниченная строка) |
| Наименование номенклатуры | не в типе реквизита, а на вкладке **Данные** самого справочника: **Длина наименования** = `100` |
| Сумма, цена, стоимость | слева **Число**, справа длина `15`, точность `2` |
| Количество | слева **Число**, справа длина `15`, точность `3` |
| Дата рождения | слева **Дата**, состав **Дата** |
| Дата документа, дата записи | слева **Дата**, состав **Дата и время** |
| Флажок | слева **Булево** |
| Выбор из справочника | слева **СправочникСсылка**, справа нужный справочник |
| Выбор из перечисления | слева **ПеречислениеСсылка**, справа нужное перечисление |
| Основание — другой документ | слева **ДокументСсылка**, справа документ `ЗаписьКлиента` |

Обязательное поле: выделите реквизит → в палитре свойств найдите **Проверка заполнения** → выберите **Выдавать ошибку**.

## 0.6. Что значит запись «Число, длина 15, точность 2»

Это **не** число «пятнадцать целых две десятых» и не значение поля. Это два отдельных числа в окне типа **Число**.

| Как написано в инструкции | Поле «Длина» | Поле «Точность» | Зачем |
| --- | --- | --- | --- |
| Число, длина 15, точность 2 | `15` | `2` | деньги: сумма, цена, стоимость |
| Число, длина 15, точность 3 | `15` | `3` | количество, как `1,000` на макете |

**Длина 15** — сколько цифр всего (до запятой и после запятой вместе).

**Точность 2** — сколько знаков **после запятой**. Для денег получится вид `1500,00`. Для количества точность 3 даёт вид `10,000`.

Как выставить:

1. Реквизит выделен. Свойство **Тип** → кнопка с буквой **T**.
2. Слева поставьте галочку только на **Число**. Если стояла галочка на **Строка**, снимите её.
3. Справа появятся поля **Длина** и **Точность**. Это не «длина строки».
4. Для суммы: длина `15`, точность `2`. Для количества: длина `15`, точность `3`.
5. При желании включите флажок **Неотрицательное**.
6. Нажмите **ОК**. В палитре тип станет выглядеть как `Число(15, 2)` или `Число(15, 3)`.

Дальше в инструкциях **нигде не пишется** сокращение «15.2». Всегда указаны слова «длина» и «точность».

---

## 0.7. Как сохранить конфигурацию и обновить базу данных

Это нужно после каждого крупного блока объектов. Без обновления новые поля не появятся в режиме 1С:Предприятие.

1. Меню **Конфигурация** → **Сохранить конфигурацию**. Можно нажать клавиши Ctrl и S одновременно.
2. Меню **Конфигурация** → **Обновить конфигурацию базы данных**. Можно нажать клавишу F7.
3. Откроется окно **Реорганизация информации**. Нажмите **Принять** или **Выполнить**.
4. Если платформа спрашивает про монопольный режим — согласитесь.

Если режим 1С:Предприятие уже был запущен, платформа попросит закрыть его перед обновлением. Закройте предприятие, повторите обновление, затем запускайте снова.

Дальше в файлах эта пара действий называется одной фразой: **сохраните конфигурацию и обновите базу данных**. Это всегда шаги 1–3 этого раздела.

---

## 0.8. Как запустить режим 1С:Предприятие для проверки

Когда объект уже создан и база обновлена:

1. В Конфигураторе меню **Отладка** → **Начать отладку**.
2. Откроется окно пользователя. Пока пользователей нет — войдите без выбора или создайте пользователя позже по файлу с данными.
3. Чтобы открыть справочник до появления подсистем спринта 2: кружок 1С в левом верхнем углу → **Все функции** → **Справочники** → нужное имя.
4. Если пункта **Все функции** нет: меню **Сервис** → **Параметры** → поставьте флажок **Отображать команду «Все функции»** → **ОК**. Затем снова откройте меню.

Для ввода демо-данных используйте файл [03-dannye.md](03-dannye.md).

---

## 0.9. Стандартные реквизиты Код и Наименование

Их **не создают** зелёным плюсом. Чтобы сменить подпись (например Код на «Таб.№», Наименование на «Ф.И.О.»):

1. Выделите объект в дереве конфигурации одним щелчком.
2. В палитре свойств прокрутите вниз до группы **Данные**.
3. Найдите строку **Стандартные реквизиты**. Справа нажмите кнопку **Открыть**. В некоторых сборках вместо слова «Открыть» стоит лупа.
4. В списке дважды щёлкните **Код** или **Наименование**.
5. В палитре свойств этого реквизита измените поле **Синоним**.

Подробный разбор с картинкой «куда жать» — в файле [01-sprint-1.md](01-sprint-1.md), раздел 1.3.

## 0.10. Что не сокращается в этой инструкции

| Не пишем | Пишем полностью |
| --- | --- |
| ПКМ | правая кнопка мыши |
| ЛКМ | левая кнопка мыши |
| ТЧ | табличная часть |
| ТЗ | учебное задание курса / макет |
| ИБ | информационная база |
| 15.2 | Число, длина 15, точность 2 |
| 15.3 | Число, длина 15, точность 3 |
| Ctrl+S без пояснения | Сохранить конфигурацию (клавиши Ctrl и S) |
| F7 без пояснения | Обновить конфигурацию базы данных (клавиша F7) |

Имена объектов платформы (`Услуги`, `СтрокаТЧ` внутри кода) **не переводите** и не разворачивайте: это служебные идентификаторы. Их копируйте как есть.

Дальше откройте [01-sprint-1.md](01-sprint-1.md) и идите по порядку: сначала все перечисления, потом справочники.
