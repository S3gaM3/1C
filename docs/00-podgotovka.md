# 0. Подготовка: ваша учебная платформа 8.3.27

Работайте только в **1С:Предприятие 8.3 (8.3.27.2130), версия для разработчиков**, режим **Конфигуратор**. Ревьюер откроет ту же учебную платформу и вашу выгрузку `.dt`.

Слова **«учебное задание»** и **«макет»** — картинки и таблицы из материалов курса. Сокращение «ТЗ» дальше не используется.

---

## 0.0. Это уже ваша база — вторую не создавайте

По окну **Справка → О программе** у вас уже есть файловая информационная база:

- наименование в списке баз: **Груминг салон**;
- каталог: `C:\Users\user\Documents\1C\GroomingSalon`;
- режим: **Файловый**;
- синоним конфигурации: **1С:Груминг салон**;
- разработчик: **Кибальник Сергей Андреевич**.

Оба спринта делаются **в этой папке**. Не нажимайте **Добавить** в списке баз, не копируйте каталог, не ставьте серверный вариант.

### Как открыть Конфигуратор каждый день

1. Ярлык **1С:Предприятие** (окно со списком информационных баз).
2. Один раз щёлкните строку **Груминг салон**. Справа в свойствах должен быть каталог `C:\Users\user\Documents\1C\GroomingSalon`.
3. Справа нажмите **Конфигуратор**. Не **1С:Предприятие** — то окно для ввода данных, не для объектов.
4. Меню **Конфигурация** → **Открыть конфигурацию**. Слева дерево с корнем `ГрумингСалон`.
5. Проверка платформы: меню **Справка** → **О программе**. Должно быть **8.3.27.2130**, приложение **Конфигуратор**, файловый режим, тот же каталог.

Если «О программе» показывает другую версию платформы или другой каталог — вы открыли не ту базу. Закройте и выберите строку **Груминг салон** с путём выше.

Раздел 0.1 (создание пустой базы) нужен **только** если каталога `C:\Users\user\Documents\1C\GroomingSalon` нет на диске. Если папка на месте — сразу к разделу 0.2.

## 0.1. Создать пустую базу (только если каталога ещё нет)

1. Ярлык **1С:Предприятие** → справа **Добавить**.
2. Точка **Создание новой информационной базы** → **Далее**.
3. Точка **Создание информационной базы без конфигурации для разработки новой…** → **Далее**.
4. **Наименование:** `Груминг салон`.
5. **Каталог:** `C:\Users\user\Documents\1C\GroomingSalon`. Папку создайте в проводнике заранее. Не указывайте каталог, в котором уже лежит другая база.
6. **Далее** / **Готово** без смены языка.
7. В списке выделите **Груминг салон** → **Конфигуратор**.

## 0.2. Свойства корня под вашу платформу 8.3.27

1. Корень дерева щёлкните **один раз**.
2. Палитра свойств: если панели нет — **Сервис** → **Палитра свойств** (или клавиши Alt и Enter). В 8.3.27 она обычно справа.
3. Заполните (если уже заполнено — сверьте, не переименовывайте имя):

| Свойство в палитре | Что должно стоять |
| --- | --- |
| Имя | `ГрумингСалон` — без пробелов |
| Синоним | `1С:Груминг салон` |
| Основной режим запуска | **Управляемое приложение** |
| Вариант встроенного языка | **Русский** |
| Поставщик | `Кибальник Сергей Андреевич` |
| Версия | перед выгрузкой спринта 1: `1.0.0.1`. Перед выгрузкой спринта 2: `2.0.0.1`. Сейчас в «О программе» может быть `2.0.0.5` — перед сдачей спринта 1 верните `1.0.0.1` |

**Имя** и **Синоним** — разные поля. Имя для платформы, синоним для заголовка и для окна «О программе».

4. Сохраните конфигурацию и обновите базу данных, как в разделе 0.7.

Учебная «версия для разработчиков» 8.3.27 для этого курса подходит. Библиотеку стандартных подсистем не подключайте: в учебной поставке её нет, и задание её не просит.

## 0.3. Три панели Конфигуратора 8.3.27

**Дерево конфигурации** — слева. Ветки: Общие, Справочники, Документы, Перечисления, Регистры накопления. Нет дерева: **Конфигурация** → **Открыть конфигурацию**.

**Окно объекта** — центр. Двойной щелчок по объекту. Вкладки: **Данные**, **Формы**, **Нумерация**, **Иерархия**, **Владельцы**, **Движения**, **Прочее**.

**Палитра свойств** — свойства выделенного. Смотрите заголовок: «Справочник Сотрудники» — весь справочник; «Реквизит Фамилия» — одно поле. Если палитра не та — щёлкните нужную строку на вкладке **Данные** ещё раз.

В 8.3.27 у длинных свойств справа часто кнопка **Открыть** (стандартные реквизиты, параметры выбора, связи параметров выбора). Это не лупа в каждой сборке: у вас на скринах была именно **Открыть**.

---

## 0.4. Как добавить любой объект

1. В дереве найдите ветку: **Справочники**, **Документы**, **Перечисления**, **Регистры накопления**.
2. **Правая кнопка мыши** по ветке → **Добавить**.
3. Сразу **Имя** (без пробелов) и **Синоним** (с пробелами).
4. Свои поля — только вкладка **Данные**, зелёный **+** над таблицей реквизитов. Код, Наименование, Номер, Дата плюсом не создают.
5. После пачки объектов: сохраните конфигурацию и обновите базу данных.

---

## 0.5. Как задать тип реквизита

1. Вкладка **Данные** — один щелчок по реквизиту.
2. Палитра → **Тип** → кнопка с буквой **T**.
3. Окно **Тип данных**: слева одна галочка; справа длина, точность или имя справочника.
4. **ОК**.

| Что нужно | Как щёлкнуть |
| --- | --- |
| ИНН | Строка, длина `12` |
| Телефон | Строка, длина `20` |
| Комментарий | Строка, длина `0` |
| Наименование номенклатуры | вкладка **Данные** справочника, **Длина наименования** = `100` |
| Сумма, цена, стоимость | Число, длина `15`, точность `2` |
| Количество | Число, длина `15`, точность `3` |
| Дата рождения | Дата, состав **Дата** |
| Дата документа, дата записи | Дата, состав **Дата и время** |
| Флажок | Булево |
| Выбор из справочника | слева СправочникСсылка, справа нужный справочник |
| Выбор из перечисления | слева ПеречислениеСсылка, справа нужное перечисление |
| Основание | слева ДокументСсылка, справа `ЗаписьКлиента` |

Обязательное поле: **Проверка заполнения** = **Выдавать ошибку**.

## 0.6. Число: длина 15, точность 2

Это не значение «15,2». Два поля в окне типа **Число**:

| Запись в инструкции | Длина | Точность | Зачем |
| --- | --- | --- | --- |
| Число, длина 15, точность 2 | `15` | `2` | сумма, цена, стоимость |
| Число, длина 15, точность 3 | `15` | `3` | количество вида `1,000` |

1. Тип → **T** → галочка только **Число**.
2. Справа **Длина** и **Точность** (не длина строки).
3. **ОК**. В палитре будет `Число(15, 2)` или `Число(15, 3)`.

## 0.7. Сохранить и обновить (файловая база 8.3.27)

1. **Конфигурация** → **Сохранить конфигурацию** (клавиши Ctrl и S).
2. **Конфигурация** → **Обновить конфигурацию базы данных** (клавиша F7).
3. Окно **Реорганизация информации** → **Принять** или **Выполнить**.
4. Монопольный режим — согласитесь. Если открыт сеанс **1С:Предприятие**, закройте его и повторите обновление.

Дальше фраза **сохраните конфигурацию и обновите базу данных** всегда означает эти шаги.

Файловый режим: база — папка `C:\Users\user\Documents\1C\GroomingSalon`. Выгрузка `.dt` — меню **Администрирование** → **Выгрузить информационную базу** (файл 04). Не используйте «Сохранить конфигурацию в файл» (это `.cf`, курс его не принимает).

## 0.8. Режим 1С:Предприятие для проверки

1. В Конфигураторе **Отладка** → **Начать отладку**. Либо закройте Конфигуратор и из списка баз нажмите **1С:Предприятие** у строки **Груминг салон**.
2. Пока нет пользователей информационной базы — войдите без выбора. Пользователей Мазаева и Оператор заведёте в пункте 2.12, в том же Конфигураторе: **Администрирование** → **Пользователи**.
3. Пока нет подсистем: кружок 1С слева сверху → **Все функции** → **Справочники** или **Документы**. Нет пункта: **Сервис** → **Параметры** → флажок **Отображать команду «Все функции»**.
4. Значения полей — [03-dannye.md](03-dannye.md).
